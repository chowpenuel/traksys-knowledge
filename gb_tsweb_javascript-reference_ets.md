# ets

This is the root namespace of the TrakSYS JavaScript API and houses the available functionality.

## Properties

```javascript
String rootPath
```

Specifies the URL path of the web application. This is typically `/ts`.

```javascript
String markdownToHtmlPath
```

Specifies the URL path for the Web API method to convert Markdown text to HTML. This is typically `/ts/api/all/util/general/ConvertMarkdownToHtml`.

```javascript
String rootApiSitePath
```

Specifies the URL path for the root Web API. This is typically `/ts/api/all`.
