# Sites

The Sites section of the TrakSYS Installation Manager displays the configured sites throughout the TrakSYS application. This page is most useful when administering a Multi-Site TrakSYS Installation.

## Configured Sites

### ID

Displays the Site ID.

### Name

Displays the Site Name.

### Status

Displays the current status of the Site.

### Delete

Deletes the selected site.

### Properties

Allows for the modification of Site-specific properties.

#### Site Name

Specifies the name of the Site as seen throughout the TrakSYS application.

#### Alternative Name

Specifies an alternate name of the Site.

#### Description

Specifies a description for this Site.

#### External Identifier

Specifies an extensible identifier of the Site that may be used as a reference between another application or lookup.

#### Page Definition Key

Defines the Key that will be used in the base URL in the web for this Site.

#### Time Zone

Declares the Time Zone of this specific Site.

#### Notes

Specifies any additional Notes about this Site.

## Actions

### Repair Administrator

Recreates the TrakSYS Administrator account.

### Repair Page Definition(s)

Repairs Page Definitions that may be affected if the Page Definition Key of a Site is edited.

### Create New Site

Allows for the creation of a new TrakSYS Site. This feature is only available when the appropriate Multi-Site TrakSYS License is present.
