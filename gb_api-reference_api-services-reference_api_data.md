# Api.Data

Contains services and methods used to manipulate (Load, Save, and Delete) the `ETS.Core.Api.Data Models`. The Db\[ENTITY] names are a one-to-one mapping to database tables in the TrakSYS database (`DbTag` corresponds to `tTag` in the database). The properties of each Db\[ENTITY] Model object are a one-to-one mapping to the fields in the corresponding tables.
