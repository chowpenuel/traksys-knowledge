# Item Log Definition

## Summary

### Entity Name

Item Log Definition

### Database Table Name

`tItemLogDefinition`

### API Object Name

`DbItemLogDefinition`

### Entity Description

An Item in TrakSYS is the database representation of a single physical item in the manufacturing process. As an Item moves around the process or transitions states, Item Log entries are created. An Item Log Definition is the specification for a type of Item Log entry. Examples of Item Log Definition are Created, Moved, Scanned, etc...

## Properties

`Item Log Definition Group [ ItemLogDefinitionGroupID ]`

Specifies the parent Item Log Definition Group.

`Code [ Code ]`

The unique string that identifies the Item Log Definition.
