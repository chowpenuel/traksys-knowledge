## Properties

`Type [ NotificationEventDefinitionType ] : ETS.Core.Enums.NotificationEventDefinitionType`

Specifies the condition for when the configured message is sent to the configured target. The possible values are:

**On Start** - Message is sent when this Event Definition starts.

**On End** - Message is sent when this Event Definition ends.
