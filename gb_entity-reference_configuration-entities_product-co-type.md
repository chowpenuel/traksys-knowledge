# Product Changeover Type

## Summary

### Entity Name

Product Changeover Type

### Database Table Name

`tProductCoType`

### API Object Name

`DbProductCoType`

### Entity Description

Product Changeover Types are definitions for changing from one Product Changeover Family to another.

## Properties

`From [ FromProductCoFamilyID ]`

The starting Product Changeover Family.

`To [ToProductCoFamilyID]`

The ending Product Changeover Family.

`Pre Duration (Minutes) [ DurationPreMinutes ]`

The changeover duration in minutes preceding a job.

`Post Duration (Minutes) [ DurationPostMinutes ]`

The changeover duration in minutes following a job.
