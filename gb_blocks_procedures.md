# Procedures

## Overview

The **Procedures Block** contains user interfaces, business logic, and capabilities for creating, viewing, and managing the core attributes of Procedure Documents (TrakSYS Blob Items).

## Capabilities

The following sections describe the various capability use-cases provided by this Block.

### Create and Manage Procedure Groups and Documents

Includes pages for managing the creation of Procedure Groups and the respective documents housed within them.

### Store Files or External Links as Procedures

This Block enables some built-in functionality for uploading files to be used or referenced as Procedures.

### View or Download Procedure Documents

Placing the included Procedure Document Content Part throughout an implementation allows users to view or download a Procedure for lineside reference.

### Manage System-Specific Procedure Groups and Document Relations

Procedures can be linked to specific Systems in TrakSYS, with pages included for managing those relationships. This can be done at the group level or per individual documents.

## Dependencies

### License

This section lists dependencies for TrakSYS Features required by this Block.

#### Advanced Scripting

Allows for extensibility via Visual Page Definitions, Content Parts and Pages, and Script Classes.

#### TrakSYS Users

Allows end-users to access TrakSYS user interfaces concurrently.

### Blocks

This section lists other Blocks that must be used for this Block to function.

#### BLOCKS.COMMON

The Procedures Block must be deployed alongside the Common Block.
