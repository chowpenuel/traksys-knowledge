# Process Definition Group

## Summary

### Entity Name

Process Definition Group

### Database Table Name

`tProcessDefinitionGroup`

### API Object Name

`DbProcessDefinitionGroup`

### Entity Description

This entity defines a grouping for organizing Process Definitions.

## Properties

`Workflow Service [ WorkflowManagerID ]`

Specifies the Workflow Service that will load and execute the Process Definitions within the Group. When a Workflow Service starts, Process Definitions within Groups assigned to the Service will be loaded and executed.
