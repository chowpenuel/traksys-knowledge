# Certificates

The Certificates section of the TrakSYS Installation Manager displays OPC UA certificate information while providing actions to manage application and server certificates.

## OPC UA Certificates

Displays the OPC UA application certificate status for each TrakSYS Service.

### Generate

Generates an OPC UA application certificate for the selected TrakSYS Service. The certificate file is saved in the root TrakSYS installation folder.

### Remove

Removes the OPC UA application certificate for the selected TrakSYS Service.

### Details

Opens a dialog displaying more information about the selected application certificate. In addition, the dialog displays a list of imported OPC Server certificates. The Import button allows for the addition of a trusted server certificate via the specified file location, while Remove allows for the removal of the selected trusted server certificate.
