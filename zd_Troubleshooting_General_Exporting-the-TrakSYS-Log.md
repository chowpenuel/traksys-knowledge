# Exporting the TrakSYS Log

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115003466434-Exporting-the-TrakSYS-Log*
*Last updated: 2025-05-21T23:11:41Z*

---

Applies To | TrakSYS 10+

The TrakSYS log file can be exported as follows:

  1. Open the TrakSYS Installation Manager and click the Diagnostics tab.  
  
![mceclip0.png](https://portal.parsec-corp.com/hc/article_attachments/360100764794)  
  

  2. Then, click the Log Viewer (DB) button to open the Log Viewer.  
  
![](/attachments/token/X59cekXJZczJTRcVtM1GC2aMQ/?name=inline1800164006.png)
  3. In the Log Viewer, select the date range for when a specific issue occurred or use Range Mode of All to export the entire log.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/115005780794)  
  

  4. Click the Export button to export the .log file and save it to a desired location.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/115004823394)
