# Fast Update Tag

### Entity Name

Fast Update Tag

### Database Table Name

`tFastUpdateTag`

### API Object Name

`DbFastUpdateTag`

### Entity Description

This entity provides a way to track sub-second tag value updates. Fast Update Tags can only be configured for OPC UA Tags, OPC DA Tags, MQTT Tags, and Smart Tags.

## Properties

`FastUpdateSetID`

This is the unique identifier (primary key) for the Fast Update Set that is used for a Fast Update Tag.

`SourceTagID`

Identifies the Tag referenced in the Fast Update Tag configuration.
