# System View

## Summary

### Entity Name

System View

### Database Table Name

`tSystemView`

### API Object Name

`DbSystemView`

### Entity Description

System Views allow arbitrarily grouping of Systems for use in visualization. Some reports offer System View filters, allowing additional flexibility in choosing which Systems to include.

## Properties

Since System Views are simply an additional way to group System Configuration Entities, their properties are shared with many other properties. See the [Common Entity Properties](../common-entity-properties) topic.
