# Batch Parameter

## Summary

### Entity Name

Batch Parameter

### Database Table Name

`tBatchParameter`

### API Object Name

`DbBatchParameter`

### Entity Description

Each row in this table represents a value recorded with a Batch or specific Batch Step.

## Properties

`BatchID`

Specifies the parent Batch.

`BatchStepID`

Specifies the parent Batch Step, if any.

`ParameterDefintionID`

Specifies the parent Parameter Definition.

`Value`

The value recorded with the Batch or specific Batch Step.
