# Notification Attachment

## Summary

### Entity Name

Notification Attachment

### Database Table Name

`tNotificationAttachment`

### API Object Name

`DbNotificationAttachment`

### Entity Description

Each row in this table represents an attachment sent along with a TrakSYS Notification.

## Properties

`NotificationID`

Identifies the Notification with which this Notification Attachment is associated.

`FileName`

Specifies the name of the Notification Attachment file.

`Url`

Specifies the URL to the Notification Attachment file.
