# Agent

The Agent section of the TrakSYS Installation Manager contains information and actions for the Agent Service.&#x20;

## Details

### State

Displays the current State of the Agent Service (i.e. Stopped, Running, etc.).

### Version

Displays the currently installed version of the Agent Service.

### Refresh

When clicked, the Agent tab will be refreshed to display the most recent information for the Agent Service.

## Actions

### Start

Starts the current Agent Service.

### Stop

Stops the current Agent Service.

### Restart

Restarts the current Agent Service.

### Update

Performs a check to see if a newer version of the Agent Service is available. If there is a newer version, the Installation Manager will install and apply the new version to the installation.

### Install

Installs the Agent Service if is it not already available on the current machine. The service handles many of the operations for TrakSYS Cloud (such as remotely performing Database Transfers and checking individual service status for a Site) and TrakSYS IQ Assistant (such as enforcing limits on interactions).

### Uninstall

Uninstalls the Agent service if it exists on the current machine.
