# Job Batch

## Summary

### Entity Name

Job Batch

### Database Table Name

`tJobBatch`

### API Object Name

`DbJobBatch`

### Entity Description

Each record in this table contains planned Batch information relating back to a Batch type Job.

## Properties

`JobID`

Specifies the parent Job.

`RecipeID`

Specifies the related Recipe.

`PlannedNumberOfBatches`

Determines the planned number of Batches for this Batch Job.

`PlannedBatchSize`

Determines the planned size of this Batch Job.

`PlannedBatchSizeUnits`

Determines the units of the given planned size for this Batch Job.
