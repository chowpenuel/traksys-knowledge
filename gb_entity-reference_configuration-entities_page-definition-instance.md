# Page Definition Instance

## Summary

### Entity Name

Page Definition Instance

### Database Table Name

`tPageDefinitionInstance`

### API Object Name

`DbPageDefinitionInstance`

### Entity Description

Each row in this table represents an instance of a Page Definition.

## Properties

`Navigation Icon CSS [ NavigationIconCss ]`

CSS that specifies the navigation icon displayed.

`Custom Entity ID 1 [ CustomEntityID1 ]`

The unique identifier of a custom entity that is to be passed in to the Page Definition instance.

`Custom Entity ID 2 [ CustomEntityID2 ]`

The unique identifier of a second custom entity that is to be passed in to the Page Definition instance.

`Refresh Key [ RefreshKey ]`

The key that will refresh the page when broadcast.
