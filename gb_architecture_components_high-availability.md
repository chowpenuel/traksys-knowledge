# High Availability

High Availability enables the configuration of a secondary host machine for TrakSYS services. In the event the primary host machine becomes unavailable, whether it is unexpected or due to scheduled maintenance activities, the services will switch to the secondary host and resume running thereby minimizing data loss due to the primary host outage.

The following TrakSYS services can be configured for High Availability:

* Logic Service
* Historian Service
* Data Management Service
* Workflow Service
