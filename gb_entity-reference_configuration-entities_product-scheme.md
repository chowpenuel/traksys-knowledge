# Product Scheme

## Summary

### Entity Name

Product Scheme

### Database Table Name

`tProductScheme`

### API Object Name

`DbProductScheme`

### Entity Description

Product Schemes define the available Attributes for Products. A Product Scheme is a set of 20 Product Attributes. Empty Attributes are created automatically when a Product Scheme is created.
