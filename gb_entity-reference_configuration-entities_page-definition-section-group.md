# Page Definition Section Group

## Summary

### Entity Name

Page Definition Section Group

### Database Table Name

`tPageDefinitionSectionGroup`

### API Object Name

`DbPageDefinitionSectionGroup`

### Entity Description

This entity defines a grouping for organizing Page Definition Sections.

## Properties

`Navigation Icon Css [ NavigationIconCss ]`

Specifies an icon (CSS class) to be used in association with the Page Definition Section Group.

`Navgiation Title [ NavigationTitle ]`

A string that is displayed in the Section Group element.

`Navigation Tooltip [ NavigationToolTip ]`

Specifies tooltip text that appears when a cursor hovers of the Section Group.
