# Job Discrete

## Summary

### Entity Name

Job Discrete

### Database Table Name

`tJobDiscrete`

### API Object Name

`DbJobDiscrete`

### Entity Description

Each row in this table contains planned Job information relating back to a Discrete type Job.

## Properties

`JobID`

Specifies the parent Job.

`PlannedProductionCount`

Determines the planned quantity to be produced during this Discrete Job.

`PlannedProductionCountUnits`

Determines the units of the given planned quantity for this Discrete Job.
