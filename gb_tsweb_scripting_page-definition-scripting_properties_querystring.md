# QueryString

## IReadOnlyDictionary QueryString

Allows access to the read-only `QueryString` Dictionary. This dictionary is populated only by the values provided in the URL Query String at the start of the Page lifecycle.

### Methods

The QueryString Dictionary implements `IReadOnlyDictionary`, which has its own set of shared extensions. See [Dictionaries](dictionaries) for more.

The QueryString Dictionary itself does not have any additional unique properties or methods.
