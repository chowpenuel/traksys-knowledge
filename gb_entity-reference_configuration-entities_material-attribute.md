# Material Attribute

## Summary

### Entity Name

Material Attribute

### Database Table Name

`tMaterialAttribute`

### API Object Name

`DbMaterialAttribute`

### Entity Description

A Material Scheme consists of a set of Material Attributes. Each Attribute defines additional information for Materials. You may define up to 20 Material Attributes for a Material Scheme.

## Properties

`MaterialSchemeID`

Specifies the parent Material Scheme.

`ColumnKey`

Specifies the column that will contain the Material Attribute. The values will be stored in one of the `Attribute01` to `Attribute20` fields.

`DataType`

The data type for the value.
