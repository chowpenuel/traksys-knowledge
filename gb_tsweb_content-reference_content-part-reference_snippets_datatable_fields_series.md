# Fields\_Series

Specifies the column from the resultant dataset that is used for **Series** grouping. When this level of grouping is used, each row will be populated with columns called **SeriesValue**, **SeriesLabel** and **SeriesDisplayOrder**.

The **SeriesValue** column typically contains the grouping entity's programmatic value (integer ID, date/time/offset value, etc.).

The **SeriesLabel** column typically contains the grouping entity's display text (string Name, formatted date/time, etc.).

The **SeriesDisplayOrder** typically contains a value that helps with sorting the grouping entity (configured DisplayOrder, etc.).
