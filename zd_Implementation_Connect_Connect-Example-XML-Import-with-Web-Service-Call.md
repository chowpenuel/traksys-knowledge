# Connect Example: XML Import with Web Service Call

*Source: https://portal.parsec-corp.com/hc/en-us/articles/23998623698451-Connect-Example-XML-Import-with-Web-Service-Call*
*Last updated: 2025-05-21T22:12:58Z*

---

Applies To | TrakSYS 12.0.1+

### Summary

This article includes an example of performing an XML Import using a Web Service Call Interface Definition combined with an XML Payload Definition. For this example, an internal Web Service Endpoint created with Connect will be called. The steps for configuring the Web Service Endpoint can be found [here](https://portal.parsec-corp.com/hc/en-us/articles/19659786617747-Connect-Example-XML-Import-with-Web-Service-Endpoint). When the Web Service is called, it executes a Module to process the imported data. The Module will contain a Module Script Step that adds the record to the tJob table.

Note that this example is meant to be used as a simple starting point for using TrakSYS Connect. Therefore, not every feature within the Web Service Call Interface Definition and XML Payload Definition is used. For more technical information about TrakSYS Connect and the settings contained within each of the entities, the [TrakSYS 12 Reference Documentation](https://support.parsec-corp.com/refdocs/12/traksys/getting-started.html) can be referenced.

### Creating a Payload Definition

The first step to using TrakSYS Connect is creating and configuring an XML Payload Definition. This helps define what type of data is used and what the expected XML data structure should be when importing and exporting content. The steps to create an XML Payload Definition can be found [here](https://portal.parsec-corp.com/hc/en-us/articles/24736728437139).

### Creating an Interface Definition

The following steps show how to create and configure an Interface Definition. This entity defines  _how_ the data will be communicated. In this case, data will be imported at a Web Service Endpoint from a Web Service Call.

  1. In the TrakSYS Web, navigate to **Developer | Connect | Interface Definitions**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25079512914067)  
  

  2. In the first slice, create a new Interface Definition Group if one does not already exist. Otherwise, select an existing Interface Definition Group.
  3. In the second slice, click the New link to create a new Interface Definition.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25079496503059)  
  

  4. Select the Web Service Endpoint option on the resulting page.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25288049913363)  
  

  5. Provide a Name and Key for the Interface Definition.   
  
![](https://portal.parsec-corp.com/hc/article_attachments/27592197337363)  
  

  6. Next, click the blue picker icon under the Message Payload Definition property and select the XML Payload created in the previous section.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/34621322943635)  
  

  7. Provide a value for the URL field. For this example, the URL of the previously configured Web Service Endpoint will be provided. This will help define the Web Service Endpoint being called, which will be called by TrakSYS. The HTTP Method will be set as POST to match the same method set for the previously configured Web Service Endpoint.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25288020253203)  
  

  8. The final result should look similar to the following:  
  
![](https://portal.parsec-corp.com/hc/article_attachments/34621322958227)  
  

  9. Click the Save button to create the Interface Definition.



### Performing a Full Compile

Now that both the Interface and Payload has been configured, a full compile is needed. This process will create and compile all Classes automatically generated by Connect based on the configuration.

**Note** : it is **strongly** recommended to turn off the Logic Service before performing a Full Compile. Otherwise, there is a chance that this process can fail. Additionally, a Full Compile **must** be performed every time changes are made to Interface Definitions or Payload Definitions. This helps ensure that all classes generated by Connect are properly created.

  1. In the TrakSYS Web, navigate to **Developer | Scripts | Web**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25079513050131)  
  

  2. In the first slice, click the Compile button.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25079513077011)  
  

  3. In the confirmation, click the Full Compile button to start the compile process.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25079513097491)  
  

  4. If the process is a success, the following confirmation dialog should be displayed:  
  
![](https://portal.parsec-corp.com/hc/article_attachments/25079496677779)



### Making a Web Service Call

While there are multiple ways to make a web service call, in this example, a Page Definition will be used. The page will be configured so that calls can be made to a service endpoint. This example assumes that the steps to create a [Web Service Endpoint](https://portal.parsec-corp.com/hc/en-us/articles/19659786617747) have been followed and that the endpoint already exists. In other words, the example makes calls from within TrakSYS to an endpoint that also exists within TrakSYS. In real world scenarios, it is more likely that the calls will be made to external endpoints instead. The steps to create this Page Definition can be found [here](https://portal.parsec-corp.com/hc/en-us/articles/25288092613779).
