# Job Capture Tag

## Summary

### Entity Name

Job Capture Tag

### Database Table Name

`tJobCaptureTag`

### API Object Name

`DbJobCaptureTag`

### Entity Description

The Job Capture Tag specifies which Tag to record to a corresponding Capture Scheme Column.

## Properties

`System [ SystemID ]`

Specifies the parent System ID.

`Job Capture Scheme Column [ JobCaptureSchemeColumnID ]`

Specifies the parent Job Capture Scheme Column.

`Capture Tag [ CaptureTagID or CaptureSourceType / CaptureSource ]`

The Tag for the Logic Service to record for the corresponding Capture Scheme Column.
