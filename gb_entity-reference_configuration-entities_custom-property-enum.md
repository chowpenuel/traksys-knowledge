# Custom Property Enum

## Summary

### Entity Name

Custom Property Enum

### Database Table Name

`tCustomPropertyEnum`

### API Object Name

`DbCustomPropertyEnum`

### Entity Description

Custom Property Enums represent possible value selections for a Custom Property.

## Properties

`Custom Property [ CustomPropertyID ]`

Specifies the parent Custom Property.

`Value [ Value ]`

Specifies the value that will be stored for the Custom Property when this choice is selected in the entry field rendered in the TrakSYS entity Property form.
