# R\_Limits\_Limit1

#### Limit 1 | Enabled

Specifies whether this limit line is enabled and visible.

#### Limit 1 | Label

Specifies the label of this limit line.

#### Limit 1 | Value

Specifies the value of the limit and therefore where it should appear on the chart.

#### Limit 1 | Color

Specifies the color of this limit line.

#### Limit 1 | Width

Specifies the width of thickness of the limit line (in pixels).

#### Limit 1 | Style

Specifies the line display style of this limit line.
