### **Introduction**

This article provides Page Definitions of a Frequently Requested Example (FRE). The pages provided are intended to provide a starting point for Developers who are looking to use more complex Development Tools. This is intended to augment the existing Training Information and Reference Documentation but is not intended to be implemented directly into a production environment. 

Attached to this article is a zipped folder that contains one or more Page Definitions. The intended way to implement these pages as well as a short description of the capability they are meant to display are listed below. Additional information about the use and purpose of the Page Definitions is included on the Pages and can be viewed once they have been imported.

### **Capability**

There are two pages provided, the Event Definition Utility and the Utility Documentation. 

The Event Definition Utility provides an import and export utility. It can be used to view and export the existing Event Definitions as an Excel document. It also has a File Upload part that can be used to import an Excel document. The import and export utilities use the same formatting to allow for quick import and export of Event Definitions. Most of the functionality is also based around the use of configurable Keys instead of IDs to support movement of Event Definitions between implementations.

The Utility Documentation provides an overview of the Event Definition Utility's functionality. It identifies the supported values and formats for all values in the Utility. 

### **Page Deployment**

Both pages are able to stand alone. They do not have any other requirements to function and can be deployed anywhere in an implementation.
