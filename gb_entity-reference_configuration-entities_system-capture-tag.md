# System Capture Tag

## Summary

### Entity Name

System Capture Tag

### Database Table Name

`tSystemCaptureTag`

### API Object Name

`DbSystemCaptureTag`

### Entity Description

The System Capture Tag specifies which Tag to record to a corresponding Capture Scheme Column.

## Properties

`System [ SystemID ]`

Specifies the parent System.

`System Capture Scheme Column [ SystemCaptureSchemeColumnID ]`

Specifies the parent System Capture Scheme Column.

`Capture Tag [ CaptureTagID or CaptureSourceType / CaptureSource ]`

The Tag for the Logic Service to record for the corresponding Capture Scheme Column.
