# CalculateXBarRControlLimit

```csharp
double CalculateXBarRControlLimit(double rangeBar, int samplesPerSubGroup)
```

This method takes the integer count of Samples per SubGroup and the RangeBar value and uses the CalculateA2XBarR method to calculate the value to be added or subtracted from the mean to reach the Upper or Lower Control Limits for an XBar Chart (for an XBar-R pairing).
