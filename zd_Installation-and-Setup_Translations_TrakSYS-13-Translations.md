**Download Information**  
  
Each download link below corresponds to a zip file containing the necessary DLLs to implement language translations throughout TrakSYS.  
  
**Requirements**  
  
The translation files on this list are only for use with TrakSYS 13. Using these files with any other version of the software will yield unexpected results.  
  
**Installation Instructions**
