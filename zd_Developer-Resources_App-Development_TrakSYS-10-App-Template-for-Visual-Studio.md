# TrakSYS 10 App Template for Visual Studio

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360020006074-TrakSYS-10-App-Template-for-Visual-Studio*
*Last updated: 2025-06-05T23:58:30Z*

---

This article describes the Visual Studio App Template for TrakSYS 10. This Visual Studio extension provides project and file templates allowing developers a quick start to creating a TrakSYS App.

**What's Included?**

The Visual Studio extension contains a Project template for creating a Web Library, item templates for adding Content Pages/Parts, and hooks for adding App installation behavior.

**System Requirements**

To use the extension the following must be installed or accessible from the development PC...

  * TrakSYS 10.2.4 or 10.2.5 (**see[here](https://portal.parsec-corp.com/hc/en-us/articles/360036072173-TrakSYS-11-App-Template-for-Visual-Studio) for TrakSYS 11 template**)  
  

  * Visual Studio 2017 with .NET Framework 4.6.2  
  

  * Access to a local or remote SQL Server (to host TrakSYS databases)



**Download and Installation**

  * Download the [VSIX installer](https://support.parsec-corp.com/downloads/TrakSysTemplates.Builder) to the development machine with the above requirements.  
  

  * Double-click the downloaded VSIX file to install the Visual Studio extension.  
  

  * Open Visual Studio.  
  

  * Click **File | New Project** from the menu and select the TrakSYS node in the left tree. Select the Web Library project type and complete the dialog by providing the standard Name and Location entries.  
  

  * Once the new Project is opened, follow the instructions on the included **readme.md** file (it should be displayed automatically after the Project is created).
