# IQ Assistant

## Summary

### Entity Name

IQ Assistant

### Database Table Name

`tIqAssistant`

### API Object Name

`DbIqAssistant`

### Entity Description

An IQ Assistant allows users to interact with the TrakSYS IQ chat window. This configuration assists in facilitating the prompts and response interactions between TrakSYS and Microsoft AI services.

## Properties

`IqAssistantGroupID`

Specifies the IQ Assistant Group ID associated with the configured IQ Assistant.

`Status`

Specifies the current synced status for the configured IQ Assistant.
