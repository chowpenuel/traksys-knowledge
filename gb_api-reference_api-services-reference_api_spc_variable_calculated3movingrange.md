# CalculateD3MovingRange

```csharp
double CalculateD3MovingRange()
```

This method calculates a D3 moving range chart. Since TrakSYS Individuals/Moving Range charts utilize the Moving Range of 2, it returns the same constant value of 0, representing the D3 values for MR size 2, which is utilized for calculating the Lower Control Limit associated with the I-MR Chart.
