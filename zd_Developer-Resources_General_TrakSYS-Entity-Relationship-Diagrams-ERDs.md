# TrakSYS Entity Relationship Diagrams (ERDs)

*Source: https://portal.parsec-corp.com/hc/en-us/articles/34282944893587-TrakSYS-Entity-Relationship-Diagrams-ERDs*
*Last updated: 2025-05-21T22:48:43Z*

---

Applies To | TrakSYS 12.0.0 - 12.0.4

This article contains the available Entity Relationship Diagrams for the TrakSYS database. A Microsoft Visio (.vsdx) file with all diagrams has been included. All tables shown in blue are configuration entities while all tables in green are considered data entities. The diagrams cover the following TrakSYS entities:

  * Sample
  * Batch
  * Event
  * Item
  * KPI/OEE
  * Task
  * Transfer (Storage Systems)
  * Production Scheduling Data
  * Workflow
  * Audit
  * Connect
  * User
  * Tag
  * Material
  * Job
  * Journal
  * Product
  * Product Changeover Configuration
  * Product Specifications (Spec)
