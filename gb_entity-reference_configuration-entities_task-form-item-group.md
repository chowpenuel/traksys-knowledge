# Task Form Item Group

## Summary

### Entity Name

Task Form Item Group

### Database Table Name

`tTaskFormItemGroup`

### API Object Name

`DbTaskFormItemGroup`

### Entity Description

A Task Form Item Group contains a set of Task Form Items. Task Form Item Groups may be referenced by multiple Task Definitions or created directly as part of a Task Form. When a Task Form Item Group is created with a Task Form, it is linked exclusively to that Task Form and cannot be referenced by Task Definitions.

## Properties

`Task Form ID [ TaskFormID ]`

Specifies the parent Task Form, if any.

`Key [ Key ]`

The unique string that identifies the Task Form Item Group.
