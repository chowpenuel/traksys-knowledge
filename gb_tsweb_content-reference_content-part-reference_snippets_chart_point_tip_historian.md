# Point\_Tip\_Historian

#### Tip | Enabled

When set to No, the tool tips for each point are not rendered.

#### Tip | Format MomentJS

Specifies the format to display the Date/Time elements of the tooltip. The TrakSYS JavaScript charts utilize standard MomentJS formats. More information can be found on the MomentJS [site](http://momentjs.com/docs/#/displaying/).

#### Tip | Decimal Places

Specifies the number of decimal places rendered for the value.

#### Tip | Use Report Display Name

When enabled, the Report Display Name is used instead of the Tag Name.
