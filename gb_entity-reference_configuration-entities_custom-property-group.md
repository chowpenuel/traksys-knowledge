# Custom Property Group

## Summary

### Entity Name

Custom Property Group

### Database Table Name

`tCustomPropertyGroup`

### API Object Name

`DbCustomPropertyGroup`

### Entity Description

A Custom Property Group is a special grouping for Custom Properties within a Custom Property Scheme. Each Custom Property Group is rendered as a section within the tab for the parent Custom Property Scheme.

## Properties

`Custom Property Scheme [ CustomPropertySchemeID ]`

Specifies the parent Custom Property Scheme.
