# args

This is used to access arguments that are passed from a triggering Notification source.

## Examples

```html
{args|SystemName}
```

This passes the System Name to the Notification message.

```html
{args|EventDefinitionName}
```

This passes the Event Definition Name to the Notification message.

```html
{args|TagName}
```

This passes the Tag Name to the Notification message.
