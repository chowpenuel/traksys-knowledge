# DatabaseConnectTimeout

```csharp
int DatabaseConnectTimeout
```

Specifies the configured Connect Timeout for the connection to the TrakSYS database. This option is configured within the Database tab of the TrakSYS Installation Manager.

{% hint style="info" %}
If the Connect Timeout setting in the TrakSYS Installation Manager is changed, a Reload Application must be performed before the new value can be displayed when using this variable.
{% endhint %}
