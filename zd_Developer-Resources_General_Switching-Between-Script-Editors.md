# Switching Between Script Editors

*Source: https://portal.parsec-corp.com/hc/en-us/articles/4415824993299-Switching-Between-Script-Editors*
*Last updated: 2025-05-21T22:49:51Z*

---

Applies To | TrakSYS 11.2.2+

### Summary

In TrakSYS 11.2.2, a new HTML5 script editor was introduced. This editor does not rely on Silverlight and can be used with modern browsers such as Google Chrome, Microsoft Edge, and Firefox. 

For situations where Internet Explorer is still required (or alternatively, IE Mode in Microsoft Edge), the Silverlight editor is available to use provided Silverlight is already installed. Note that as of October 12th, 2021, Silverlight is no longer supported or distributed by Microsoft. If Silverlight is not present, a plaintext editor can be used instead. In addition, as of June 15th, 2022, Internet Explorer is no longer supported by Microsoft.

When switching between editors, the following should be considered:

  * The HTML5 editor is not compatible with Internet Explorer.
  * The HTML5 editor is not compatible with mobile browsers.
  * The Silverlight editor is only compatible with Internet Explorer. 
  * The Plaintext editor can be used on any browser. However, it does not include advanced features such as IntelliSense and syntax highlighting.
  * The Silverlight editor is no longer available starting with TrakSYS 12.



This article explains how to switch between editors and the different areas in which the editor options can be accessed.

### Procedure

The following steps explain how to switch between script editors using the Settings page.

  1. Open the TrakSYS Web and login with an existing user.
  2. Click the user name in the top right corner of the navigation bar and click the Settings option.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18852339608339)  
  

  3. Click the Editor Settings link under the Actions section of the first slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18852377870611)  
  

  4. On the resulting page, choose the desired editor in the Type field. Descriptions for each of the options under this field are available on the third slice. Note that the HTML5 editor has an additional dropdown that allows the user to pick a Dark or Light theme. Click the Save button to apply the changes.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18852437395859)  
  

  5. The selected type will now be used when a script editor is accessed by the user.



### Switching Script Editors When Using The HTML5 Editor

When using the HTML5 Editor, an extra Editor Configuration button available on the top corner of the options bar.

![](https://portal.parsec-corp.com/hc/article_attachments/18852516593043)

Clicking this button will redirect the user to the Editor page shown in step 4 of the previous section. After selecting the desired options and saving them, the user will be redirected back to the editor screen.
