# System View System

## Summary

### Entity Name

System View System

### Database Table Name

`tSystemViewSystem`

### API Object Name

`DbSystemViewSystem`

### Entity Description

Each row in this table establishes a relationship between a System in the configuration and a System View to create an alternate grouping mechanism for view, dashboard, or reporting purposes.

## Properties

`SystemViewID`

Specifies the parent System View.

`SystemID`

Specifies the parent System.
