# Job Capture Scheme

## Summary

### Entity Name

Job Capture Scheme

### Database Table Name

`tJobCaptureScheme`

### API Object Name

`DbJobCaptureScheme`

### Entity Description

A Job Capture Scheme defines the Job Capture Scheme Columns associated with a Job. Once you assign Job Capture Tags to your Job's Capture Scheme Columns, the Logic Service will record the values of the Capture Tags as supplementary data in matching columns for each Event. Capture Tags work similarly to VTRs, but the reports allow you to group and filter by Capture Columns rather than merely view the captured values in a detail view.
