# Module Scripts

Module Scripts can be defined centrally under the Module Scripts Hub of the Developer Section.

## Use

Module Scripts can be used for creating classes or extensions which can be implemented and accessed throughout the Data Management Service.

Module Scripts can be shared across all Data Management Service Modules or limited to a single Module through the Module Script Group. This is controlled by the Module property, which specifies a single Module when selected or applies to all Modules when set to None.

## Best Practices

Web Scripts should be Test Compiled using the button at the top of the script editor to ensure there are no compilation errors before publishing the script. The Data Management Service must be restarted when a Module Script is created or edited.
