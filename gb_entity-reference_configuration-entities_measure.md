# Measure

## Summary

### Entity Name

Measure

### Database Table Name

`tMeasure`

### API Object Name

`DbMeasure`

### Entity Description

This entity provides a way to define different types of custom measurements. The TrakSYS API can be used to perform bidirectional conversions between each measurement.

## Properties

`Measure Group [ MeasureGroupID ]`

Specifies the parent Measure Group.

`Abbreviation [ Abbreviation ]`

Contains the text or symbol used to represent the Measure.
