# Why are configured Tags not selectable in Tag Pickers when assigning Tags to Configuration Entities in TrakSYS 12?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/15842653622675-Why-are-configured-Tags-not-selectable-in-Tag-Pickers-when-assigning-Tags-to-Configuration-Entities-in-TrakSYS-12*
*Last updated: 2025-05-21T21:53:32Z*

---

Applies to | TrakSYS 12+

Configured tags may not be selectable for Configuration Entities (e.g., Systems, Event Definitions, etc.) if a Logic Service Instance is not assigned to the Tag Group. If an instance is not assigned, then all associated Tags may not be selectable within the pickers when using the built-in configuration pages. This is true even if the individual tags exist and are correctly configured. Assigning a Logic Service Instance to the Tag Group should allow Tags to be selectable for other configuration entities.
