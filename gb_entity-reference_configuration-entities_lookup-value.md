# Lookup Value

## Summary

### Entity Name

Lookup Value

### Database Table Name

`tLookupValue`

### API Object Name

`DbLookupValue`

### Entity Description

A Lookup Value is a single key/value pair and a member of a parent Lookup Set.

## Properties

`Lookup Set [ LookupSetID ]`

Specifies the parent Lookup Set.

`Value [ Value ]`

The value represented by this item in the Lookup Set.
