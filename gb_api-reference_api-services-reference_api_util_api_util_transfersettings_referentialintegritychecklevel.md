# ReferentialIntegrityCheckLevel

```csharp
ReferentialIntegrityCheckLevel ReferentialIntegrityCheckLevel
```

This ready-only property retrieves an Enumeration value from the **ReferentialIntegrityCheckLevel** setting in the TrakSYS Settings. The Enumeration values for this setting can be found under `ETS.Core.Enums.ReferentialIntegrityCheckLevel`.
