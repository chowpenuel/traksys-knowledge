# LogData

This object is used to provide values for the Log Data (`tLog.Data`) when creating new log records. This object is used by many of the methods in the `ApiService.Notification` section of the API.

## Properties

`string Name`

Specifies a name used for the Log Data.

`object Value`

Specifies the value that will be provided in the `tLog.Data` field for a given log entry.
