# Why does the "An unknown server error occurred" error message appear when activating a license?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/14813046726675-Why-does-the-An-unknown-server-error-occurred-error-message-appear-when-activating-a-license*
*Last updated: 2025-05-28T17:55:22Z*

---

Applies To | TrakSYS 10+

It may be possible to receive the "An unknown server error occurred" message when activating the license online through the TrakSYS Installation Manager or [manually](https://portal.parsec-corp.com/hc/en-us/articles/115000983914-TrakSYS-Manual-License-Activation) using the [Manual License Activation Page](https://support.parsec-corp.com/license/activation).

![](https://portal.parsec-corp.com/hc/article_attachments/14813205481619)

This situation can occur when changes are made to the license feature lines (e.g. purchasing new features or increasing/decreasing the count on existing feature lines), but the license file was never replaced within the installation. When changes like these are made to the license, a new license file is generated and it must be imported into the TrakSYS installation. The following steps should be taken to resolve the issue:

  1. Remove the current license in the installation.
  2. Import the license file with the new/updated feature lines.
  3. Attempt to activate the license.



If a new or updated copy of the license file is needed, [submit a request](https://portal.parsec-corp.com/hc/en-us/requests/new) to support. The [License Serial Number](https://portal.parsec-corp.com/hc/en-us/articles/360003777014-How-Do-I-Find-My-License-Serial-Number-) will be required for the request.
