# How Do I Reload IntelliSense?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115005140113-How-Do-I-Reload-IntelliSense*
*Last updated: 2023-10-27T09:48:37Z*

---

Applies To | TrakSYS 10 | TrakSYS 11 | TrakSYS 12

In some cases, it may be necessary to Reload IntelliSense while writing code in a script editor window. For example, to address Intellisense-related errors or to refresh Intellisense if it is not working as expected.

IntelliSense can be reloaded by clicking the Reload IntelliSense button in a code editor. The location for this button is shown for both the HTML5 and Silverlight-based editors:
