# Getting Started

## Reference Documentation

TrakSYS is a powerful and proven manufacturing operations management software. It offers a wide range of capabilities designed to deliver scalable and extensible solutions to meet your exact requirements. The TrakSYS solution platform is designed to leverage existing assets, resources, and infrastructure to significantly improve production management without disrupting normal operations. The TrakSYS scalable feature set makes it possible to choose the right functionality for current projects without risking obsolescence later as your needs change.

## Organization

The TrakSYS Reference Documentation is a hierarchical collection of sub-documents, each with its own specific purpose and focus. Each document contains an overview description and its own sections and organizational scheme.

## Target Audience

The Reference Documentation is intended as a reference guide to a TrakSYS administrator or power user, who is already familiar with the basic purpose and operation of the software. While there are some fundamental definitions contained within in order to establish common terminology, the Reference Documentation is not intended to serve as a training guide for learning the entire product from the start, nor as a functional description of the problems sets for which TrakSYS is intended to create solutions. Parsec provides many other sales, marketing and training resources to serve these purposes from the main website ([https://www.parsec-corp.com](https://parsec-corp.com)) or Support Portal ([https://portal.parsec-corp.com](https://portal.parsec-corp.com)).
