# Example Discrete Plugin Execution

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360046038413-Example-Discrete-Plugin-Execution*
*Last updated: 2024-07-08T20:48:28Z*

---

Applies To | TrakSYS 11 | TrakSYS 12

### Summary

Production Scheduling plugins come in two formats, one for discrete system use and one for batch system use. Each version comes with scripting hooks that can be used to add implementation-specific logic to the standard scheduling logic. However, without a previous understanding of the logic, it is not always clear when each method will execute.

  * Runs against a PsSet with 2 Systems (IDs: 1, 2)
