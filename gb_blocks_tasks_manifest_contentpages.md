# Content Pages

## Task Attachment Delete

This page is built to delete Task Attachments by providing a TaskAttachmentID. It has no UI. It completes the Delete and returns to the previous page. It was designed to work with the TaskDetails Content Part to simplify the process of creating, viewing, and deleting Task Attachments from a single part.

### Properties

#### Task Attachment ID

The ID of the Task Attachment that will be deleted.

### Visualization

This page does not have any visual elements.
