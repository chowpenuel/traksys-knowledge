# CalculateSigmaControlLimitUpper

```csharp
double CalculateSigmaControlLimitUpper(double sigmaBar, int samplesPerSubGroup)
```

This method takes the integer count of Samples per SubGroup and the SigmaBar value and uses the CalculateB4Sigma method to calculate the value to be added to the mean to reach the Upper Control Limits for a Sigma Chart.
