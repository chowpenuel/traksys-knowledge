# Step Code

## Summary

### Entity Name

Step Code

### Database Table Name

`tStepCode`

### API Object Name

`DbStepCode`

### Entity Description

Step Codes help organize similar or related Step Categories. These are useful for relating Step Categories to an existing business categorization scheme. Once Step Categories are related to Step Codes, the corresponding Step Code is associated with when operators categorize a Batch Step.

## Properties

`Step Code Group [ StepCodeGroupID ]`

Specifies the parent entity in the configuration hierarchy.

`Code`

Custom alphanumeric `string` which uniquely identifies the Step Code.
