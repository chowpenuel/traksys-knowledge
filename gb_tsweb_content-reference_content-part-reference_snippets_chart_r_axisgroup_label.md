# R\_AxisGroup\_Label

#### Label | Font Size

Specifies the font size for each group label.

#### Label | Format Moment JS

Specifies the format to display group label that is a Date/Time. The TrakSYS JavaScript charts utilize standard MomentJS formats. More information can be found on the MomentJS [site](http://momentjs.com/docs/#/displaying/).

#### Label | Min / Max Rotation

Specifies the angle boundaries for which each group label will dynamically rotated in order to fit.

#### Label | Max Characters

Specifies the maximum number of characters to display in each group label.
