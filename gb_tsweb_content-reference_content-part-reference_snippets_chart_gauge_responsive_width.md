# Gauge\_Responsive\_Width

#### Width | LG

Specifies the width (in bootstrap 1-12) for the part when it is rendered in bootstrap LG screen sizes. A value of 0 indicates that the property value for Width (SM) should be used.

#### Width | MD

Specifies the width (in bootstrap 1-12) for the part when it is rendered in bootstrap MD screen sizes A value of 0 indicates that the property value for Width (SM) should be used.

#### Width | XS

Specifies the width (in bootstrap 1-12) for the part when it is rendered in bootstrap XS screen sizes A value of 0 indicates that the property value for Width (SM) should be used.
