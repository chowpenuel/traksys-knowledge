# Module Step Connect Pull

## Summary

### Entity Name

Module Step Connect Pull

### Database Table Name

`tModuleStepConnectPull`

### API Object Name

`DbModuleStepConnectPull`

### Entity Description

Defines a pull-style interface connection for a Module Step. Each record links a specific Module Step to an Interface Definition that it pulls data from or communicates with during execution.

## Properties

`Module Step ID [ ModuleStepID ]`

Specifies the parent Module Step.

`Interface Definition ID [ InterfaceDefinitionID ]`

Specifies the parent Interface Definition.
