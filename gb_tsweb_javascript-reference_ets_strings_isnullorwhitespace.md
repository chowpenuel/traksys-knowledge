# isNullOrWhiteSpace

```javascript
Boolean isNullOrWhiteSpace(String source)
```

Checks if the source is null or white spaces.

## Parameters

```javascript
String source
```

## Examples

```javascript
ets.strings.isNullOrWhiteSpace('hello'); // returns false

var myObj;
ets.strings.isNullOrWhiteSpace(myObj); // returns true

ets.strings.isNullOrWhiteSpace('      '); // returns true
```
