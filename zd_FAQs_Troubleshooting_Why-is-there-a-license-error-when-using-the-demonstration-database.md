# Why is there a license error when using the demonstration database?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115002790888-Why-is-there-a-license-error-when-using-the-demonstration-database*
*Last updated: 2025-05-28T17:59:42Z*

---

Applies To | TrakSYS 10+

When connected to the **Demonstration Database** , the license error shown below will appear in the TrakSYS Web if a single-site license is being used.

![](https://portal.parsec-corp.com/hc/article_attachments/115003530474)

This problem can be solved by deleting the single site license and importing a multi-site license.
