# KPI Capture Tag (OEE Capture Tag)

## Summary

### Entity Name

KPI Capture Tag

### Database Table Name

`tOeeCaptureTag`

### API Object Name

`DbOeeCaptureTag`

### Entity Description

The KPI Capture Tag specifies which Tag to record to a corresponding Capture Scheme Column.

## Properties

`OEE Calculation [ OeeCalculationID ]`

Specifies the parent Oee Calculation.

`OEE Capture Scheme Column [ OeeCaptureSchemeColumnID ]`

Specifies the parent Oee Capture Scheme Column.

`Capture Tag [ CaptureTagID or CaptureSourceType / CaptureSource ]`

The Tag for the Logic Service to record for the corresponding Capture Scheme Column.
