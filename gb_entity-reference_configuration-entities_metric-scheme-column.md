# Metric Scheme Column

## Summary

### Entity Name

Metric Scheme Column

### Database Table Name

`tMetricSchemeColumn`

### API Object Name

`DbMetricSchemeColumn`

### Entity Description

Each row in this table represents a data column for a Metric Scheme.

## Properties

`Metric Scheme ID [ MetricSchemeID ]`

Specifies the parent Metric Scheme.

`Column Key [ ColumnKey ]`

Key string used to identify the column number (values `01` - `10`).

`Data Type [ DataType ] : ETS.Core.Enums.DataType`

The data type of the Metric Scheme Column.
