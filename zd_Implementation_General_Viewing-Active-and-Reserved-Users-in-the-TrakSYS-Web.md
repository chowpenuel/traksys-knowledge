# Viewing Active and Reserved Users in the TrakSYS Web

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115004920274-Viewing-Active-and-Reserved-Users-in-the-TrakSYS-Web*
*Last updated: 2025-05-21T22:08:23Z*

---

Applies To | TrakSYS 10.1.5+

### **Summary**

In TrakSYS 10.1 Update 5 (10.1.5) and later, the ability to check the currently Active and Reserved Users was added to the TrakSYS Web. This is useful for keeping track of how many user slots are currently taken and which devices are using the TrakSYS Web. This article explains where in the TrakSYS Web Active and Reserved Users can be viewed. 

### **Procedure**

  1. Open the TrakSYS Web.
  2. Navigate to **Administration | Diagnostics | Active Users**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18545153302419)  
  

  3. A table of Active and Reserved Users will be displayed on the resulting page.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18545215707539)  
  

  4. Reserved Users will have a value of True in the Is Reserved field for the entry. The user shown in the screenshot above is an Active User, but is not a Reserved User.
