# CalculateRangeControlLimitLower

```csharp
double CalculateRangeControlLimitLower(double rangeBar, int samplesPerSubGroup)
```

This method takes the integer count of Samples per SubGroup and the RangeBar value and uses the CalculateD3Range method to calculate the value to be subtracted from the mean to reach the Lower Control Limits for a Range Chart.
