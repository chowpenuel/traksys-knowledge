# Reporting Services

The Reporting Services section of the TrakSYS Installation Manager displays the the current status of SQL Reporting Services and includes actions for installing standard reports and the TrakSYS data source for the Reporting Services platform.

## Status

### RS Available

Displays whether or not a connection to Reporting Services is available and reachable.

### Reports Deployed

Displays whether or not TrakSYS Reports have been deployed.

## Settings

### Server URL

Displays the base URL for reaching Reporting Services.

### Virtual Directory

Specifies the virtual directory of the Reporting Services installation.

### Path

Specifies the path TrakSYS is pointed to for Reports.

## Actions

### Deploy Reports

Deploys the standard reports to the path specified above.

### Set Data Source

Creates an EDB Data Source in Reporting Services which points to the TrakSYS Database.
