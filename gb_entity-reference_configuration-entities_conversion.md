# Conversion

## Summary

### Entity Name

`tConversion`

### API Object Name

`DbConversion`

### Entity Description

Used to specify conversions between configured [Units of Measure](measure).

## Properties

`Conversion Group ID [ ConversionGroupID ]`

Specifics the parent Conversion Group.

`From Measure ID [ FromMeasureID ]`

Specifies the Measure to convert from.

`To Measure ID [ ToMeasureID ]`

Specifies the Measure to convert to.

`Multiplier [ Multiplier ]`

Specifies the multiplier that is applied to the conversion value.

`Add Factor [ AddFactor ]`

Specifies a factor that is added to the conversion value.
