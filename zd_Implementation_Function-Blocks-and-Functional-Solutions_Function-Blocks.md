### Summary

Function Blocks were introduced alongside TrakSYS 14 as a way to standardize and accelerate some of the basic development needed when starting an implementation.

Function Blocks represent some of the most common pages, parts, and scripts created when starting a typical implementation. They serve as a starting point and incorporate TrakSYS development best practices. Therefore, when extending these Blocks, the patterns should be followed to prioritize maintainability and standardization across TrakSYS implementations.

Complete documentation can be found [here](https://docs.parsec-corp.com/blocks).

For version history, see [here](https://docs.parsec-corp.com/blocks/previous-versions).
