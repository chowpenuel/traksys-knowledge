# ENTITY Tag Relationship

## Summary

### Entity Name

Entity Tag Relationship

### Database Table Name

`tENTITYTagRelationship`

### API Object Name

`DbENTITYTagRelationship`

### Entity Description

Tag Relationships provide a way to associate Tags with a specific entity. There is no data collected or stored automatically as a result of configuring Tag Relationships, they exist for extensibility purposes only (for instance creating a report that trends a set of Tags based on the selected entity).

## Common Properties

`Relate Tag [ RelateTagID ]`

The Tag that will be associated with this entity.

`Abbreviation [ Abbreviation ]`

A shorter name or abbreviation for the related Tag.
