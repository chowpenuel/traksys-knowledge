# Material Consumption Method

## Summary

### Entity Name

Material Consumption Method

### Database Table Name

`tMaterialConsumptionMethod`

### API Object Name

`DbMaterialConsumptionMethod`

### Entity Description

A Material Consumption Method defines how material usage is recorded and interpreted within the application. Material Consumption Methods are typically used to standardize how consumption is captured and reported for production execution and is implementation dependent.

## Properties

`Material Consumption Method Group [ MaterialConsumptionMethodGroupID ]`

Specifies the parent Material Consumption Method Group.

`Material Consumption Method Type [ MaterialConsumptionMethodTypeID ]`

A Material Consumption Method Type categorizing this Material Consumption Method (solely for organizational and reporting purposes).
