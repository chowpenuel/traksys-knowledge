# Services

The Services section of the TrakSYS Installation Manager displays currently installed TrakSYS Services while providing actions to install, remove, start, restart, and stop services.

## Installed Services

Provides a table of TrakSYS Services and their current status.

### Service

Displays the name of the TrakSYS Service.

### Status

Displays the current status of the particular TrakSYS Service (i.e. Running, Stopped, Not Installed).

### Remove

Uninstalls the selected TrakSYS Service.

### Start

Starts the selected TrakSYS Service.

### Restart

Restarts the selected TrakSYS Service.

### Stop

Stops the selected TrakSYS Service.

### Refresh

Refreshes this view of the TrakSYS Installation Manager to fetch the latest statuses of all Services.

## Actions

### Install Logic

Installs the TrakSYS Logic Service on this machine. The TrakSYS Logic Service is responsible for the real-time data collection and interaction throughout the application. Results of the installation can be viewed exported.

### Install Historian

Installs the TrakSYS Historian Service on this machine. The TrakSYS Historian Service is responsible for historizing data throughout the application. Results of the installation can be viewed and exported.

### Install Data Management

Installs the TrakSYS Data Management Service on this machine. The TrakSYS Data Management Service is responsible for periodically running calculations on data and other developer defined modules throughout the application. Results of the installation can be viewed and exported.

### Install Workflow

Installs the TrakSYS Workflow Service on this machine. The TrakSYS Workflow service is responsible for decision control orchestration of Visual Workflow Management processes. Results of the installation can be viewed and exported.

### Install Maintenance

Installs the TrakSYS Maintenance Service on this machine. The TrakSYS Maintenance Service is responsible for running ancillary tasks throughout the application too keep the system running smoothly. Results of the installation can be viewed and exported.
