# ResourceableListItem

This is a generic Object Model that is used in several areas of the TrakSYS software. It provides an object that stores values and their respective (readable) names.

## Properties

`ResourceStringItem Text`

Specifies the text that will represent the value. This is typically what is displayed to the user.

`string Value`

Specifies the raw integer value included in this Object Model. This value is typically used in parts and code that process data.
