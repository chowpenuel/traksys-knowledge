# Reloading the TrakSYS Application

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360006969353-Reloading-the-TrakSYS-Application*
*Last updated: 2025-05-21T22:09:43Z*

---

Applies To | TrakSYS 10+

Reloading the TrakSYS Application may be required when switching databases or changing web settings within the TrakSYS Installation Manager. The Reload Application button can be found on the Settings page. This page also contains a list of commonly used web settings as well as information about the TrakSYS server and database.

In order to Reload the TrakSYS Application, do the following:

  1. Open the TrakSYS Web (typically http://<servername>/ts[)](http://<servername>/ts\)) and navigate to **Administration | Settings**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18554677162131)  
  

  2. Click the Reload Application button on the bottom of the page.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18554717039251)  
  

  3. When the application successfully reloads, the Web Loaded field on the first slice should now display the last time the Web Application was loaded. In this case, it should show the current Date/Time as the value.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18554774629907)
