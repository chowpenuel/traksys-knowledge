# CommonProperties

`Name [ Name ]`

Identifies the entity throughout the application.

`Alternate Name [ AltName ]`

This field is another name by which to reference the entity. This field can only be seen by users with access to edit the properties of the page.

`Description [ Description ]`

Provides an area for documenting a written description or purpose of an entity. This field can only be seen by users with access to edit the properties of the page.

`Notes [ Notes ]`

Provides an area for additional details and notes about an entity. This field can only be seen by those with access to edit the properties of the page.

`Guid [ Guid ]`

Globally Unique Identifier - a 128-bit read-only number generated by TrakSYS.
