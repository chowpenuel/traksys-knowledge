# Log Custom

## Summary

### Entity Name

Log Custom

### Database Table Name

`tLogCustom`

### API Object Name

`DbLogCustom`

### Entity Description

This table contains custom log entries typically generated by custom code for extensibility purposes. TrakSYS does not create entries in this table by default.

## Properties

`LogDateTime`

The date and time that the log entry was created by the API script call.

`Message`

Contains the text message when the error, warning, or informational message was created.

`Category`

Specifies the category that the message belongs to when it was generated. TrakSYS has a number of built-in categories, however, custom categories can also be defined if the message is generated programmatically using the TrakSYS API.

`Type : ETS.Core.Enums.LogTypeCustom`

* **Information** = 1
* **Debug** = 2
* **Warning** = 3
* **Error** = 4
* **Critical** = 5

`Data`

Contains any additional data that was included with the Log message.

`ManagerID`

Specifies the service instance ID of the TrakSYS service that created the log entry. For example, if the Logic Service created the entry, it will contain the `tLogicManager.ID` value of the configured Logic Service Instance.
