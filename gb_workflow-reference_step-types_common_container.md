# Container

This Step Type allows users to create logical groupings for multiple, related Step Types on a Workflow Diagram. The step contains an editable title and can be resized to fit multiple steps as needed. When the Container is moved within the Workflow editor, any other Step Types contained within it will also be moved. Paths can be created to link Step Types inside and outside of the container. However, paths cannot be created to the Container Step Type itself. This Step Type is used for display purposes only and does not have any additional properties.
