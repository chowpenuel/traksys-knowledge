# Batch Quality Loss Category

## Summary

### Entity Name

Batch Quality Loss Category

### Database Table Name

`tBatchQualityLossCategory`

### API Object Name

`DbBatchQualityLossCategory`

### Entity Description

Batch Quality Loss Categories are reasons that can be assigned to bad production as the result of a Batch. A Batch Quality Loss Category is similar to Event Category for Events.

## Properties

`Batch Quality Loss Category Group [ BatchQualityLossCategoryGroupID ]`

Specifies the parent Batch Quality Loss Category Group.
