# Behavior\_Zoom

#### Behavior | Enable Zoom

Determines whether or not the zoom functionality will be enabled on the initial load of this chart.

#### Behavior | Zoom Buttons Enabled

Determines whether or not the Zoom Buttons will appear on the initial load of this chart.

#### Behavior | Zoom Buttons Layout

Specifies the visual layout of the Zoom Buttons. Possible values are...

**Horizontal Left**

**Horizontal Right**

**Vertical**
