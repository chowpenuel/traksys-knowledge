# Why does the TrakSYS Web still show pages from the previous database after pointing TrakSYS to a new database?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/16375213684371-Why-does-the-TrakSYS-Web-still-show-pages-from-the-previous-database-after-pointing-TrakSYS-to-a-new-database*
*Last updated: 2025-05-21T21:58:32Z*

---

Applies To | TrakSYS 10+

The TrakSYS Web may still show pages from the previous TrakSYS database if the database connection settings were changed in the TrakSYS installation Manager. The connection information also needs to be updated in the TrakSYS Web. This can be accomplished by [Reloading the TrakSYS Application](https://portal.parsec-corp.com/hc/en-us/articles/360006969353-Reloading-the-TrakSYS-Application). After the application has been reloaded, pages can now be viewed for the current database.
