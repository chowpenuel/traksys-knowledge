# Notification Target

## Summary

### Entity Name

Notification Target

### Database Table Name

`tNotificationTarget`

### API Object Name

`DbNotificationTarget`

### Entity Description

A Notification Target is a list of TrakSYS Users (Windows or built in TrakSYS Type Users) that make up a logical Target for notification messages. Because Notification Targets are defined independently of the logic that triggers the message, they can be re-used in many different places in the configuration, reducing the need to constantly re-define which Users are to be sent specific messages.

## Properties

`Notification Target Group [ NotificationTargetGroupID]`

Specifies the parent Notification Target Group.
