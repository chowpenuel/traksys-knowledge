# DatabaseDisplayName

```csharp
string DatabaseDisplayName
```

Specifies the Database Name using the `DatabaseServer.DatabaseName` format. This information is provided when connection information is specified to connect to the TrakSYS database.

{% hint style="info" %}
If the database connection is changed in the TrakSYS Installation Manager, a Reload Application must be performed before the new value can be displayed when using this variable.
{% endhint %}
