# Script Library

## Summary

### Entity Name

Script Library

### Database Table Name

`tScript`

### API Object Name

`DbScript`

### Entity Description

The Script Library is where reusable code can be defined and stored. Each Script entry here can contain namespaces and classes written in the C#.NET language. Publicly declared objects can be referenced from within Advanced Script Tags and the Script sections of the Logic Service Properties page.

The Script Library is only available when the Advanced Script Tag feature is licensed. See also Script Class Templates.

## Properties

`Script Group [ ScriptGroupID ]`

Specifies the parent Script Group.

`Script [ Script ]`

Holds the script content for the Script entry.
