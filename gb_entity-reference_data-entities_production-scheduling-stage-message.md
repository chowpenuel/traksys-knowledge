# Production Scheduling Stage Message

## Summary

### Entity Name

Production Scheduling Stage Message

### Database Table Name

`tPsStageMessage`

### API Object Name

`DbPsStageMessage`

### Entity Description

Each row in this table represents a message generated during Production Scheduling staging of Jobs. The message can be system generated or custom.

## Properties

`Production Scheduling Stage ID [ PsStageID ]`

The unique identifier of the Production Scheduling Stage for which the message was generated.

`Message [ Message ]`

Content of Stage Message.
