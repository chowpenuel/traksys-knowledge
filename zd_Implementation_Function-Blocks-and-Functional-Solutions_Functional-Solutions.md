### Summary

Functional Solutions were introduced alongside TrakSYS 14 to bundle multiple Function Blocks and offer various out-of-the-box solutions, or at a minimum, standardized starting points for purpose-built implementations. Functional Solutions can also include Dashboards, Reports, and other components that are specific to that bundle -- i.e. not included in any of the individual Blocks.

The Function Blocks that comprise Functional Solutions provide a standardized, extensible foundation for TrakSYS implementations. In addition to working directly out of the box, they also set clear patterns and structures using standard TrakSYS development techniques and implementation best practices. The Blocks provide clear areas where they can be extended as necessary using the established patterns and structures.

  
Complete documentation can be found [here](https://docs.parsec-corp.com/solutions).

For version history, see [here](https://docs.parsec-corp.com/solutions/previous-verions).
