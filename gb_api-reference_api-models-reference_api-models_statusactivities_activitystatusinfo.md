# ActivityStatusInfo

This object is used when executing the Long Running Status Activity within the TrakSYS Web.

## Properties

`DateTimeOffset EndDateTime`

Gets or sets the End Date/Time for a specific entry in the Long Running Status Activity.

`string IconCss`

Gets or sets the Icon for a specific entry in the Long Running Status Activity.

`string Message`

Gets or sets the Message for a specific entry in the Long Running Status Activity. This is the actual message that is logged to the User Interface (UI) when the Long Running Status Activity is running.

`DateTimeOffset StartDateTime`

Gets or sets the Start Date/Time for a specific entry in the Long Running Status Activity.
