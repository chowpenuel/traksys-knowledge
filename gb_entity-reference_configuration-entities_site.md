# Site

## Summary

### Entity Name

Site

### Database Table Name

`tSite`

### API Object Name

`DbSite`

### Entity Description

Sites define top-level partitions of configuration and data in TrakSYS. Sites are commonly used to separate plants, facilities, or business units.

## Properties

`External ID [ ExternalID ]`

External identifier for the Site. This value is also used as the Site identifier in the URL.

`Time Zone [ TimeZoneID ]`

Specifies the Site time zone used for time-based display and calculations.
