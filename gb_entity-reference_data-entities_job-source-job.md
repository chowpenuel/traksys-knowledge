# Job Source Job

## Summary

### Entity Name

Job Source Job

### Database Table Name

`tJobSourceJob`

### API Object Name

`DbJobSourceJob`

### Entity Description

This table allows for a Job to have multiple parents, with each record for a given Job ID specifying a distinct source/parent Job.

## Properties

`SourceJobID`

Specifies the Source Job ID linked to the Child Job.

`JobID`

Specifies the Job ID for the current Job entry.
