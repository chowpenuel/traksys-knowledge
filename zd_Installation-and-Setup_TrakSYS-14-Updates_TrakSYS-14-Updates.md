**Download Information**  
  
This download contains a single update executable. The executable updates all necessary files for TrakSYS 14. All TrakSYS 14 updates are cumulative. To update TrakSYS 14 to the latest version, only the last update needs be downloaded and installed.  
  
**Installation Instructions**

  * The [full setup](https://portal.parsec-corp.com/hc/en-us/articles/47243455170963) for TrakSYS version 14 must be installed on the target machine prior to running the update executable. **Do not apply the update if version 14 is not installed on the target machine**.
  * Stop all TrakSYS services/applications before the patch executable is run. This includes the TrakSYS Logic, Historian, Data Management, Workflow, and Maintenance services.
  * Backup the TrakSYS database before the update executable is run.
  * After the update executable is run, restart applicable TrakSYS services and applications.
