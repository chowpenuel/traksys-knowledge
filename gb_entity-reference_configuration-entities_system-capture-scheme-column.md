# System Capture Scheme Column

## Summary

### Entity Name

System Capture Scheme Column

### Database Table Name

`tSystemCaptureSchemeColumn`

### API Object Name

`DbSystemCaptureSchemeColumn`

### Entity Description

This entity defines a Data Type and capture behavior for a specific column in the System Capture Scheme.

## Properties

`System Capture Scheme [ SystemCaptureSchemeID ]`

Specifies the parent System Capture Scheme.

`Data Type [ DataType ] : ETS.Core.Enums.DataType`

The data type for the Column.

`Column Key [ ColumnKey ]`

A string indicating the column number (values `01` - `10`).
