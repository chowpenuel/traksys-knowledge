# Changing Text Color Using CSS

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115004655208-Changing-Text-Color-Using-CSS*
*Last updated: 2025-05-21T22:52:14Z*

---

Applies To | TrakSYS 10+

### **Summary**

This article describes how to leverage the built-in CSS Classes and TrakSYS color palette to enhance just the text color of any HTML or Content Parts. Similar to how the background color of many Content Parts can be changed, the text color can be changed and not the background.

### **Examples**

#### **Example 1**

The following example shows how to change the default colors of a paragraph of text from black to bright red.
    
    
    <p class="tstext-c-red-bright">The text color is Red - Bright</p>
    

#### **Example 2**

This example shows how to change an existing Content Part's text color.

  * Add a `Paragraph` Content Part
  * Set the Text property to "Hello, this text is the color bright red"
  * Set the Advanced | CSS Class to "tstext-c-red-bright"
  * Save and/or Preview the results.
