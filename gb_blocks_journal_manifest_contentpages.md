# Content Pages

## Journal Attachment Delete

This page is built to delete Journal Attachments by providing a JournalAttachmentID. It has no UI. It completes the Delete and returns to the previous page. It was designed to work with the JournalDetails Content Part to simplify the process of creating, viewing, and deleting Journal Attachments from a single part.

### Properties

#### Journal Attachment ID

The ID of the Journal Attachment that will be deleted.

### Visualization

This page does not have any visual elements.
