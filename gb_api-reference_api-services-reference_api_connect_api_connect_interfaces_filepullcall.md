# FilePullCall

```csharp
Result<List<ETS.Core.Api.Models.TsConnect.TsConnectInterfaceItem<ETS.Core.Scripting.TsConnect.PAYLOADDEFINITIONKEY>>> FilePullCallINTERFACEDEFITIONKEY([int parentInterfaceTransactionID])
```

This method executes a file pull using a File Pull Interface Definition for a given `parentInterfaceTransactionID`. The name of this class is dynamically generated and depends on the Key that has been specified for the TrakYS Connect configuration. For the method signature above, replace `PAYLOADDEFINITIONKEY` with the key used for the configured Payload Definition and replace `INTERFACEDEFITIONKEY` with the key used for the Interface Definition.
