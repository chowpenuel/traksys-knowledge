# Web Scripts

Web Scripts can be defined centrally under the Web Scripts Hub of the Developer Section.

## Use

Web Scripts can be used for creating classes or extensions which can be implemented and accessed throughout the web-development sections of the application, such as Page Definition Scripts and Content Page Scripts. A fully-fledged web API can even be written under the Web Scripts for use within the TrakSYS Application.

## Best Practices

Web Scripts must be Full Compiled using the button at the top of the HTML5 Script Editor. This will fully compile and publish the code for use within the TrakSYS web development environment.
