# State Machine

## Summary

### Entity Name

State Machine

### Database Table Name

`tStateMachine`

### API Object Name

`StateMachine`

### Entity Description

Each row in this table represents a configured State Machine.

## Properties

`State Machine Group ID [ StateMachineGroupID ]`

The parent State Machine Group.

`Get State Script [ GetStateScript ]`

Content of script called to get the current state value from the model.

`Change State Script [ ChangeStateScript ]`

Content of script called to set the new state value to the model.
