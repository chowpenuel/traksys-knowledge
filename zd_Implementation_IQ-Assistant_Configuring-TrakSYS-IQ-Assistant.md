# Configuring TrakSYS IQ Assistant

*Source: https://portal.parsec-corp.com/hc/en-us/articles/44857917808275-Configuring-TrakSYS-IQ-Assistant*
*Last updated: 2026-06-12T21:39:57Z*

---

### Summary

An AI-powered chat assistant capable of retrieving, transforming, presenting, and explaining data. IQ Assistant can query data from user-defined Views and Lookup Sets to deliver meaningful and contextual responses. Custom queries can be applied to Views, and Lookup Sets can be created to provide human-readable terms for entity identifiers such as IDs or Keys.

TrakSYS also supports configuring multiple Assistants, each with distinct permissions for the Views and Lookup Sets they can access. This allows organizations to tailor Assistants for different departments or teams. Permissions can grant or restrict an Assistant’s ability to return information related to specific topics, ensuring that sensitive data is available only to authorized users or groups.

This article outlines the steps required to configure TrakSYS IQ Assistants, Views, Lookup Sets, and associated permissions.

#### Requirements and Licensing

  * An active internet connection is **required** to use TrakSYS IQ Assistant.
  * Ports **80** and **443** must be open for inbound and outbound traffic to support Assistant synchronization and the retrieval of responses to user prompts.

  * The **TrakSYS IQ Assistant Interactions** Feature Line must be present on the TrakSYS license.

  * The number of responses for TrakSYS IQ Assistant is a shared pool between all users and licenses for any given Site. This means that any responses given for any given user or given environment (e.g., production, development, test, etc.) counts against the Site total. **Note** : **Any** response that is given (**even an error message**) will count towards the Site total.

  * Notifications for Site usage warnings can be configured in the TrakSYS Cloud portal. Additionally, daily limits can also be configured to prevent going through too many responses too quickly.



#### Limitations and Behavior

While using TrakSYS IQ Assistant, there are some limitations and behaviors to be aware of when results are provided. Many of these points come from the AI functionality and cannot be modified:

  * **The accuracy of the answers generated by TrakSYS IQ Assistant is NOT guaranteed**. There can be scenarios where this functionality may provide incorrect answers. Additionally, similar questions phrased differently may produce different answers.
  * The voice to text feature (e.g., the microphone button) is supported for Microsoft Edge and Google Chrome. This feature is disabled in Firefox and is not supported in this browser.
  * When using TrakSYS IQ Assistant to generate charts, it uses the Chart.js library that is automatically included with the TrakSYS software. Only charts included in this library are supported for this functionality. This includes the following charts:
    * Line
    * Line Step
    * Bar
    * Horizontal Bar
    * Radar
    * Doughnut
    * Pie
    * Polar Area
    * Bubble
    * Scatter
    * Mixed
    * Area
    * Combo
  * TrakSYS IQ Assistant often presents information from the same thread used in previous responses unless explicitly instructed to check for new data. To ensure up-to-date information, it is recommended to create a new thread if this behavior is not desirable.
  * In some very rare instances, TrakSYS IQ Assistant may respond with messages that may have parsing errors. If this happens, it is recommended to resubmit the request to regenerate the response.
  * TrakSYS IQ Assistant may have difficulties in customizing certain aspects of generated charts. That may include actions such as adding data values labels, resizing charts, customizing bar width, and customizing bar spacing.
  * Any changes made to an Assistant’s configuration require the Assistant to be resynced to apply the updates.
  * Changes to the TrakSYS configuration require all Assistants to be resynced and the Logic Service to be restarted.
  * If an Assistant sync fails with a **“** Failed to retrieve NegotiateEndpoint**”** error, restarting the TrakSYS Agent Service resolves the issue for subsequent sync attempts.
  * If users are close to reaching the response limit and a user creates a new thread, the warning regarding limited responses may not appear for the initial response. However, it will appear on further responses for the same thread.



### Configuring Assistants

TrakSYS IQ Assistant provides the ability to configure multiple Assistants. Each Assistant can be used to assign different permissions (covered in a later section) for different purposes. If a Multi-Site implementation is used, Assistants can be configured at each individual Site level or the Root Site to apply to all Sites. The following steps explain the standard procedure for creating Assistants.

  1. In the TrakSYS Web, navigate to **Developer | IQ | Assistants**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027869590035)  

  2. On the first slice, click the New button to create an Assistant Group. If an Assistant Group already exists, go directly to step 4.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027885475731)  

  3. Provide a Name and a Key. Then, click Save.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027885478291)  

  4. Select the Assistant Group and click the New button on the second slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027869601427)  

  5. Provide a Name for the IQ Assistant, then click Save.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48967765311635)  

  6. Repeat steps 4 and 5 to create additional Assistants as needed. For this example, three different Assistants have been created.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027885493651)  

  7. Once the Assistants have been created, click the Sync button in the third slice. Note that this will need to be performed for each individual Assistant.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027869610771)  

  8. On the resulting page, click the Sync button to start the sync process to the cloud.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027869614355)  

  9. The results of the operation will be displayed on the resulting page. If the operation fails for any reason, error messages will be logged to the Steps section within the middle slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/46518492081299)  
  
**Note** : Steps 7 through 9 will need to be performed each time there are changes to the Assistant Configuration or the TrakSYS Configuration.



### Configuring Views

TrakSYS IQ Assistant uses Views in the TrakSYS database to query information and return relevant results based on the user's prompt. The Views can be imported, exported, or created directly within the TrakSYS Web. Expand each of the sections below for the full instructions on how to Import, Export, and create new Views in the TrakSYS Web.

**Note** : The Name of all configured Views **must** be unique across all Assistants and all Sites (if a Multi-Site license is being used).

Importing Views

#### Importing Views

The following steps describe importing existing TrakSYS IQ Assistant Views into a TrakSYS installation. The file containing the exported views will use a .iqv file extension type.

  1. In the TrakSYS Web, navigate to **Developer | IQ | Assistants**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027869590035)  

  2. Select the desired Assistant Group on the first slice and the configured Assistant on the second slice. On the third slice, click the Views link under the Related section.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45028680863635)  

  3. On the resulting page, click the Import button on the second slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45028648544147)  

  4. Select the desired .iqv file and provide a meaningful Prefix for the imported Views. Doing so will help ensure that the View names are unique when other Views are imported or created. Once this information has been provided, click the Import button to import the Views.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48967775772307)  

  5. Once the import is successful, a full list of the available Views should now appear in the second slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48967765319827)  

  6. After all Views have been imported, the changes will need to be synced for the Assistant. This process is shown in steps 7 through 9 of the "Configuring Assistants" section above.



Exporting Individual Views

#### Exporting Individual Views

The following steps describe exporting a single existing TrakSYS IQ Assistant View to a .iqv file. This file can be used to transfer views to different environments and TrakSYS installations.

  1. In the TrakSYS Web, navigate to **Developer | IQ | Assistants**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027869590035)  

  2. Select the desired Assistant Group on the first slice and the configured Assistant on the second slice. On the third slice, click the Views link under the Related section.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45028680863635)  

  3. On the resulting page, select the desired View on the second slice. Then click the Export button on the third slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48967765327123)  

  4. This will immediately create the .iqv file for the View.



Exporting All Views for an Assistant

#### Exporting All Views for an Assistant

The following steps describe exporting all existing TrakSYS IQ Assistant Views for an Assistant to a .iqv file. This file can be used to transfer views to different environments and TrakSYS installations.

  1. In the TrakSYS Web, navigate to **Developer | IQ | Assistants**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45027869590035)  

  2. Select the desired Assistant Group on the first slice and the configured Assistant on the second slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/46522076375699)

![](https://portal.parsec-corp.com/hc/article_attachments/46522076379795)

### Configuring Lookup Sets

This helps provide a more natural response to user prompts. Lookup Sets can be imported, exported, or created directly within the TrakSYS Web. ### Configuring Permissions for Assistants

When configuring multiple Assistants, it is possible to configure access permission for Roles. More specifically, permissions to access the TrakSYS IQ Assistant chat window can be denied or granted. Additionally, it is possible to grant or revoke permissions to specific Views generated for TrakSYS IQ Assistants. This allows more control over what type of content can be returned to a user for a given prompt. Note that [Roles and Page Permissions](https://portal.parsec-corp.com/hc/en-us/articles/115001575094-Configuring-Page-Permissions-for-Roles) must be configured before configuring access to Assistant Views. The following steps describe how to configure permissions for Views.

#### TrakSYS IQ Assistant Chat Window Permissions

The following steps describe the process for configuring access to the TrakSYS IQ Assistant Chat Window. This controls who will be able to access the TrakSYS IQ Assistant functionality and whether users will see the IQ Chat option on the top navigation bar in the TrakSYS Web.

  1. In the TrakSYS Web, navigate to **Administration | Roles**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45160730468115)  

  2. In the first slice, select the desired Role. Then, on the third slice, click the Edit button.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48968661342867)  

  3. On the resulting page, navigate to the TrakSYS tab. Within the list of options, the IqAssistantChat option will be available. Checking this option will give access to the TrakSYS IQ Assistant functionality and will allow the IQ option to appear within the top navigation bar of the TrakSYS Web. If this option is unchecked, any users assigned to this Role will not see the IQ option on the top navigation bar and will see an error message if they attempt to access any part of the TrakSYS IQ Assistant functionality.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48969025095187)  

  4. Click Save to apply the changes.



#### TrakSYS IQ Assistant View Permissions

The following steps describe the process for configuring access to individual TrakSYS IQ Assistant Views. This can be used to provide more granular access to specific information if users are meant to have access to TrakSYS IQ Assistant, but not all information provided within a specific Assistant.

  1. In the TrakSYS Web, navigate to **Administration | Roles**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45160730468115)  

  2. In the first slice, select the desired Role. Then, on the third slice, click the Edit button.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48968661342867)  

  3. Within the Role configuration, navigate to the IQ Views tab.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/45160730479763)  

  4. This tab will display a table of all configured Assistants for a given Site. If the installation is using a Single Site license, then all Assistants will be displayed. Within each Assistant, entries for all configured Views will be selectable. To grant access to a specific View, ensure that the checkbox is checked. If all Views should be accessible, the top View checkbox can be checked.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/48968471029139)  

  5. Once the selections have been made, click Save to apply the changes.
