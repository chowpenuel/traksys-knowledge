# CalculateSigmaControlLimitLower

```csharp
double CalculateSigmaControlLimitLower(double sigmaBar, int samplesPerSubGroup)
```

This method takes the integer count of Samples per SubGroup and the SigmaBar value and uses the CalculateB3Sigma method to calculate the value to be subtracted from the mean to reach the Lower Control Limits for a Sigma Chart.
