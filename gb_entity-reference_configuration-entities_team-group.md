# Team Group

## Summary

### Entity Name

Team Group

### Database Table Name

`tTeamGroup`

### API Object Name

`DbTeamGroup`

### Entity Description

Team Groups define named groupings used to organize Teams. Team Groups can be site-specific or global depending on whether a Site is assigned.

## Properties

`Site [ SiteID ]`

Specifies the parent Site, if any.

`Key [ Key ]`

Unique key for the Team Group.
