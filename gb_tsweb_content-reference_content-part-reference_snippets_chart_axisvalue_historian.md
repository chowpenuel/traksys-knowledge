# AxisValue\_Historian

#### Tag History Definition

Specifies the Tag History Definition that will be displayed on the chart. This field accepts the `ID` values from the `tTagHistoryDefinition` Table.

#### Minimum Value

Specifies the minimum value to be displayed on the Y-Axis of the chart.

#### Maximum Value

Specifies the maximum value to be displayed on the Y-Axis of the chart.

#### Color

Specifies the color of the plot line (for line charts) or border (for slice, bar, area, etc...). This field accepts color names (e.g. Red) and hex codes (e.g. #FF0000).

#### Line Style

Specifies the line style of the plot line (for line charts) or border (for slice, bar, area, etc...). This field accepts the following values:

* solid
* dot
* dash
* dashdot
* dashdotdot

#### Marker Style

Specifies the marker style for each point in the chart. This field accepts the following values:

* circle
* cross
* dash
* line
* star
* triangle

#### Axis Mode

Specifies how many axes will be displayed. Possible values are...

**Single Y Axis** - The chart will display a single Y axis to display all values. Each data set will be shown to scale based on the Y axis range.

**Multiple Y Axis** - The chart will display multiple Y axes to display all values. Each data set will be displayed based on either Y axis range.
