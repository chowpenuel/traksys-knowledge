# TrakSYS Manual License Activation

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115000983914-TrakSYS-Manual-License-Activation*
*Last updated: 2025-01-28T20:23:53Z*

---

**Does Not Apply to Online Subscription Licenses**

Follow these steps to install and manually activate your TrakSYS™ license file.

  1. Import your TrakSYS license file (e.g. SN0000000000.ts11lic) using the TrakSYS™ Installation Manager application.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/115003305793)  
  

  2. Set the Host to the correct computer name hosting each of the listed features.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/115003306053)
  3. Generate the Activation Cypher file (*.tsactexport) by clicking on "Create Activation Data".  
  
![](https://portal.parsec-corp.com/hc/article_attachments/115003334754)
  4. Acknowledge that the Host Name values are correct and save the file.
  5. Upload the Activation Cypher file (*.tsactexport) [**here**](https://support.parsec-corp.com/license/activation). Alternatively, email Cypher file to [Support](mailto:support@parsec-corp.com) and Activation Key will be emailed back.
  6. Save the downloaded or emailed Activation Key (*.tsactivate).
  7. Import the Activation Key by clicking on "Import Activation Data" in Installation Manager.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/115003306473)



After completing the steps above, the license status should display "Present and Valid".

![](https://portal.parsec-corp.com/hc/article_attachments/115003306513)

If you experience any technical difficulties or failures during the activation process, please **[submit a request](https://portal.parsec-corp.com/hc/en-us/requests/new)** to Parsec Support.
