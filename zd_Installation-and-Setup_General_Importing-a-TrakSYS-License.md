# Importing a TrakSYS License

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360017383954-Importing-a-TrakSYS-License*
*Last updated: 2026-03-05T23:14:45Z*

---

Applies To | TrakSYS 10 | TrakSYS 11 | TrakSYS 12

The following describes how to import a license using Installation Manager.

  1. Open Installation Manager and click the License tab.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/19190455370899)  
  

  2. Click the Delete License button. This step is not required if there is no license already in place (in this case, the Delete License button will be greyed out).  
  
![](https://portal.parsec-corp.com/hc/article_attachments/19190491551891)  
  

  3. Click the Import License button and import a single-site or multi-site license.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/19190520631443)  
  

  4. In the Administration section of the TrakSYS Web, navigate to Settings and click on Reload Application.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/19190545046547)  
![](https://portal.parsec-corp.com/hc/article_attachments/19190601895571)
