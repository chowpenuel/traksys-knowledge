# Exporting and Importing Page Definitions

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360003817653-Exporting-and-Importing-Page-Definitions*
*Last updated: 2025-05-21T22:43:20Z*

---

Applies To | TrakSYS 10+

### **Summary**

Importing and exporting Page Definitions can be useful when transferring pages between multiple installations of TrakSYS or between different Sites. This export/import process is also required when moving Page Definitions up, down, or across sections of the page hierarchy (e.g. Sections, Hubs, and Spokes). This article explains the standard procedure for Exporting and Importing Page Definitions.

### **Procedure**

#### **Page Definition Export**

  1. Open the TrakSYS Web and navigate to **Developer | Page Definitions**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655554545043)  
  

  2. Select the desired Section, Hub, or Spoke under the Sections slice. For this example, a Section Page Definition is being exported.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655644595603)  
  

  3. Click Export on the third slice.   
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655694033299)  
  

  4. Save the .pdef file to an easy-to-access location (e.g. the desktop or the downloads folder).
  5. The file should now be accessible in the saved location.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655676501011)



#### **Page Definition Import**

  1. Open the TrakSYS Web and navigate to **Developer | Page Definitions**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655709351443)  
  

  2. Select the desired Section, Hub, or Spoke that the Page Definition will be placed under. In this Example, a Section Page Definition is being selected. The page will be imported as a Hub 1 to the Section.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655783717139)  
  

  3. On the third slice, click the Hubs button under the Related section.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655810140435)  
  

  4. On the resulting page, click the New Hub 1 button under the Hubs section of the second slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655818723091)  
  

  5. On the New Page Definition page, navigate to the Import tab and click the blue file picker button to select the .pdef file.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655867987347)  
  

  6. Once the file has been selected, enter a Key for the page. Then click the New button to import the page.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655929591827)  
  

  7. The newly imported Page Definition should now appear as a Hub 1 under the selected Section.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18655916962579)
