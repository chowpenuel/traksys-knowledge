# Test Run

## Summary

### Entity Name

Test Run

### Database Table Name

`tTestRun`

### API Object Name

`DbTestRun`

### Entity Description

Test Runs provide a structure for storing data related to automated testing with NUnit. This table is for extensibility purposes as there is nothing built into TrakSYS that automatically interfaces with NUnit.

## Properties

`StartDateTime`

Specifies the Date/Time stamp of when a test was initiated.

`EndDateTime`

Specifies the Date/Time stamp of when a test was completed.

`SelectedTestCount`

Specifies the total number of tests selected for the current execution.
