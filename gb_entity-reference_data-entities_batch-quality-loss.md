# Batch Quality Loss

## Summary

### Entity Name

Batch Quality Loss

### Database Table Name

`tBatchQualityLoss`

### API Object Name

`DbBatchQualityLoss`

### Entity Description

Each row of this table represents some quantity of bad product created during a Batch. This quantity can be assigned a Batch Quality Loss Category.

## Properties

`BatchID`

Specifies the parent Batch.

`BatchQualityLossCategoryID`

Specifies the related Batch Quality Loss Category.

`Quantity`

Specifies the amount of bad product created during the Batch.
