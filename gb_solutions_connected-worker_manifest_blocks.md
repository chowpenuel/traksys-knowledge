# Function Blocks

## Common

The Common Block includes core functionality and structures used by other Blocks.

## Orders

The Orders Block enables the creation of orders in TrakSYS along with a handful of many helpful end-user interfaces for assigning, starting, stopping, and amending bills of materials.

## Journal

The Journal Block includes user interfaces for real-time communication via Journal entries and replies plus external notifications to Teams to prompt escalation or promote feedback and open dialogue.

## Tasks

The Tasks Block includes multiple user interfaces for managing the creation, configuration, and trigger logic around Task Forms. It also includes parts and pages to make the completion of Task Forms seamless, including custom input rendering, focused form guidance, and SOPs and attachments.

## Procedures

The Procedures Block allows for the simplified management of core attributes of Procedure Documents (TrakSYS Blob Items) which may be referenced throughout TrakSYS, most notably in Task Forms.
