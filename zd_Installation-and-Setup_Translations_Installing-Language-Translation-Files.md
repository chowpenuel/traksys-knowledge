# Installing Language Translation Files

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115005265807-Installing-Language-Translation-Files*
*Last updated: 2026-03-10T23:43:35Z*

---

### Summary

The steps below describe the process of deploying translation resource files in order to provide additional language support to the TrakSYS application.

### Procedure

  1. Close any browsers on the server running the TrakSYS Web application.  

  2. Stop all TrakSYS services: Logic Service, Maintenance Service, Historian Service and Data Management Service (if applicable).  

  3. Copy the downloaded TrakSYS Resources zip file for the language of interest to the TrakSYS application server.   

  4. Right-click on the zip file and select "Extract All".  

  5. Specify the destination as the "Parsec" folder of the TrakSYS installation directory (e.g. C:\Program Files\Parsec\ or C:\Program Files (x86)\Parsec\ prior to TrakSYS 12) and click "Extract".  
  
  
![](https://portal.parsec-corp.com/hc/article_attachments/21699815135763)
  6. Restart TrakSYS services.  

  7. Reload the TrakSYS Web application on any applicable browsers.
