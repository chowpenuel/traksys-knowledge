# Role

## Summary

### Entity Name

Role

### Database Table Name

`tRole`

### API Object Name

`DbRole`

### Entity Description

Roles define named security roles used to group permissions for users. Roles can be site-specific or global depending on whether a Site is assigned.

## Properties

`Site [ SiteID ]`

Specifies the parent Site, if any.

`Key [ Key ]`

Unique key for the Role.
