# Changing a Site's Time Zone

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115004946653-Changing-a-Site-s-Time-Zone*
*Last updated: 2025-05-21T22:09:50Z*

---

Applies To | TrakSYS 10+

### **Summary**

TrakSYS now allows the time zone to be set for individual Sites. This can be especially useful for Multi-Site installations of TrakSYS that have Sites using time zones that are different from the central TrakSYS server. However, the time zone of a Site can be changed on Single-Site installations of TrakSYS as well.

Having the incorrect time zone for a Site may return incorrect or unexpected data in reports for a site. This article explains the standard procedure for changing the time zone of a site.

### **Procedure**

  1. Open the TrakSYS Installation Manager and navigate to the Sites tab.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/41183586503955)  
  

  2. Select the desired site and click the Properties button. If a Single-Site license is being used, only one Site should appear in the list.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/115005689793)  
  

  3. In the Site Properties window, a new time zone can be specified for the Site.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18620706824723)  
  

  4. Click OK to save the changes.
  5. The updated time zone can then be verified by opening the TrakSYS Web and navigating to **Administration | Settings**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18620687925267)  
  

  6. If the information does not update immediately, click the Reload Application button.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18620738337299)
