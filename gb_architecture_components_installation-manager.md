# Installation Manager

The TrakSYS Installation Manager is the central application for managing the different aspects of a TrakSYS installation including the license, database, and services. The different dashboards allow an installation administrator or implementor to adjust global TrakSYS settings for all Sites, manage Sites at a high level, and view diagnostic information. It is also the main dashboard for managing the state of the various TrakSYS services and components. See the [Installation Manager](../../installation-manager) topic for further details.
