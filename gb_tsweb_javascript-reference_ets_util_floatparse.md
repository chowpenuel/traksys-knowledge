# floatParse

```javascript
Number floatParse(Any val)
```

This function attempts to convert the val parameter to a Float

## Parameters

```javascript
Any val
```

Can be a String or Number

## Examples

### Basic Examples

```javascript
ets.util.floatParse(123.456); // returns 123.456
ets.util.floatParse('9.25'); // returns 9.25
```
