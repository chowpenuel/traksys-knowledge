# Exporting Version Information Using Installation Manager

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115003466294-Exporting-Version-Information-Using-Installation-Manager*
*Last updated: 2025-05-21T23:11:33Z*

---

Applies To | TrakSYS 10+

The following describes how to export TrakSYS version information from Installation Manager.

  1. Navigate to the TrakSYS Installation Manager Overview tab.  
  
![mceclip0.png](https://portal.parsec-corp.com/hc/article_attachments/1500001914561)  
  

  2. Click the Version Information button.  
  
![mceclip1.png](https://portal.parsec-corp.com/hc/article_attachments/1500001868082)  
  

  3. On the TrakSYS Version Summary page, click Results.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18697121412115)  
  

  4. On the Results for TrakSYS Version Summary, click the Export button to export the results to an XML file.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18697184986259)
