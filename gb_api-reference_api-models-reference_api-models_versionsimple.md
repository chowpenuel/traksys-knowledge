# VersionSimple

This Object Model is used to display the TrakSYS version in various areas of the TrakSYS software. The Model can also be used to display the version using custom code.

## Properties

`int Major`

Specifies the `Major` version number in the full version string. This is the first number that is included in the full TrakSYS Version (e.g. TrakSYS **12**.0.4, TrakSYS **14**.0.0, etc.).

`int Minor`

Specifies the `Minor` version number in the full version string. This is the second number that is included in the full TrakSYS Version (e.g. TrakSYS 12.**0**.5, TrakSYS 14.**0**.0, etc.).

`int Build`

Specifies the `Build` number in the full version string. This is the third number that is included in the full TrakSYS Version (e.g. TrakSYS 12.0.**4**, TrakSYS 14.0.**0**, etc.).
