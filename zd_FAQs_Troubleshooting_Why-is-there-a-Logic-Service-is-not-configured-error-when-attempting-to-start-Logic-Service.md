# Why is there a "Logic Service is not configured..." error when attempting to start Logic Service?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115007960527-Why-is-there-a-Logic-Service-is-not-configured-error-when-attempting-to-start-Logic-Service*
*Last updated: 2025-05-28T17:58:27Z*

---

Applies To | TrakSYS 10+

In order for the Logic Service to successfully start, a Logic Service entry must be created and configured for the application server. If a user attempts to start the Logic Service without one, an error similar to the one below will be displayed in Installation Manager:

![](https://portal.parsec-corp.com/hc/article_attachments/115013929308)
