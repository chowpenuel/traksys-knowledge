# Step Category Scheme

## Summary

### Entity Name

Step Category Scheme

### Database Table Name

`tStepCategoryScheme`

### API Object Name

`DbStepCategoryScheme`

### Entity Description

Step Category Schemes allow the definition of hierarchical levels associated with Step Categories. For example, the first level of Step Categories may represent Reasons, whereas the second level may represent Sub-Reasons. Using Step Categories with levels and a Step Category Scheme, you can define a complete hierarchy which are presented to operators for selection. The reports also use Step Category Schemes to properly label Step Category levels.
