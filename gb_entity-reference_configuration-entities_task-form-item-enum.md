# Task Form Item Enum

## Summary

### Entity Name

Task Form Item Enum

### Database Table Name

`tTaskFormItemEnum`

### API Object Name

`DbTaskFormItemEnum`

### Entity Description

Task Form Item Enums represent possible value selections for a Task Form Item.

## Properties

`Value [ Value ]`

Specifies the value that will be stored for the Task Form Item if this choice is selected in a data entry user interface.
