# Icon\_PassFail

#### Icon | Pass

Specifies icon CSS to be returned in the column called **IconCssPassFail** when the Task represented by the row has been marked as **Passed**. This column in the resultant dataset can be used to dynamically populate icon properties in table and list parts.

#### Icon | Fail

Specifies icon CSS to be returned in the column called **IconCssPassFail** when the Task represented by the row has been marked as **Failed**. This column in the resultant dataset can be used to dynamically populate icon properties in table and list parts.

#### Icon | Unknown

Specifies icon CSS to be returned in the column called **IconCssPassFail** when the Task represented by the row has been marked as **Unknown**. This column in the resultant dataset can be used to dynamically populate icon properties in table and list parts.
