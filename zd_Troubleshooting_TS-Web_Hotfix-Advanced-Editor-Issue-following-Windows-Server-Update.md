# [Hotfix] Advanced Editor Issue following Windows Server Update

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360059357793--Hotfix-Advanced-Editor-Issue-following-Windows-Server-Update*
*Last updated: 2023-10-27T09:48:43Z*

---

Applies to | TrakSYS 10 | TrakSYS 11 (up to 11.1.1)

**Issue**

Client machines experience undesirable effects in the Silverlight Advanced Editor page after installing a Windows Server update. 

  * Lightbox dialog does not automatically appear on Test or Full Compilation.



![mceclip2.png](https://portal.parsec-corp.com/hc/article_attachments/360097476774/mceclip2.png)

  * Navigation Tree is not displayed after being toggled.



![mceclip1.png](https://portal.parsec-corp.com/hc/article_attachments/360097474174/mceclip1.png)

  * Navigation Bar and Footer disappears from view when switching through multiple open tabs.



![mceclip3.png](https://portal.parsec-corp.com/hc/article_attachments/360099777733/mceclip3.png)

**Resolution**

There is a version-specific hotfix available for this issue. Please contact [support@parsec-corp.com](mailto:support@parsec-corp.com) to request it, making sure to include the exact [TrakSYS version installed](https://portal.parsec-corp.com/hc/en-us/articles/236323008-Verifying-the-Installed-Version).

Note that when upgrading to a new version, the hotfix will be overwritten. A version-appropriate hotfix will have to be re-applied.
