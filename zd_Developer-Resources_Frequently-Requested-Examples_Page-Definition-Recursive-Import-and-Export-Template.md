### **Introduction**

This article provides Page Definitions of a Frequently Requested Example (FRE). The pages provided are intended to provide a starting point for Developers who are looking to use more complex Development Tools. This is intended to augment the existing Training Information and Reference Documentation, but is not intended to be implemented directly into a production environment. 

Attached to this article is a zipped folder that contains one or more Page Definitions. The intended way to implement these pages as well as a short description of the capability they are meant to display are listed below. Additional information about the use and purpose of the Page Definitions is included on the Pages and can be viewed once they have been imported.

### **Capability**

These pages show an example of importing and exporting Page Definitions through an intermediary Json file. It allows for an entire Section of the implementation, including the child Page Definitions, to be exported together. The example pattern has a limited scope and has specific requirements for the Pages it intends to Import and Export. The requirements can be found on the provided Page Definitions as part of the instructions. 

This capability can be expanded for use with any entity from the TrakSYS database, and can be extended to work with multiple types of entities at once if needed. It can also delete or write over existing work and progress if it is not used carefully. **While all pages and all content should be done with best practices and proper caution, it is highly recommended to take an extra set of precautions when first using and implementing this pattern.**

### **Page Deployment**

The attached folder contains two Visual pages. They can be deployed independently and can be deployed in different implementations, so long as the version of the implementations are compatible. For testing purposes, it is recommended to deploy these in a development environment. They do not need to be deployed in any specific hierarchy.
