# Journal Category

## Summary

### Entity Name

Journal Category

### Database Table Name

`tJournalCategory`

### API Object Name

`DbJournalCategory`

### Entity Description

Journal Categories are predefined types that can be applied to Journal entries. A Journal Category defined here is listed in the Journal entry forms.

## Properties

`Journal Category Group [ JournalCategoryGroupID ]`

Specifies the parent Journal Category Group.
