# Diagnostics

The Diagnostics section of the TrakSYS Installation Manager includes a Log Viewer and Mail connection tests.

## Actions

### Log Viewer (DB)

Displays a diagnostic view of the Log from the TrakSYS database. Data is shown to the right of a selected log data row. The filtered data can be refreshed and exported as needed. Filters include the following:

* Range Mode
* Type
* Category
* Application
* Host
* Message

### Log Viewer (Import)

Meant to import and view a Log Viewer Export file. This is helpful for quick diagnostic and debugging between teams and servers.

### Send Test E-Mail

Sends a brief test e-mail to the provided target e-mail address sent from the configured notification e-mail address.
