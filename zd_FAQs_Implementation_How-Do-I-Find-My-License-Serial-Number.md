# How Do I Find My License Serial Number?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360003777014-How-Do-I-Find-My-License-Serial-Number*
*Last updated: 2025-05-21T21:59:22Z*

---

Applies To | TrakSYS 10+

The License Serial Number can be found in multiple locations throughout the TrakSYS Installation Manager and the TrakSYS Web. All of these locations are explained below.

#### **TrakSYS Installation Manager**

The License Serial Number can be found in the License tab of the TrakSYS Installation Manager. It is located in the Serial Number field under the License section.

![](https://portal.parsec-corp.com/hc/article_attachments/41175366378387)

#### **TrakSYS Version Information**

The License Serial Number can also be found in the TrakSYS Version Information. To view the Version Information, do the following:

  * Open the TrakSYS Installation Manager and navigate to the Overview tab.
  * Then, click the Version Information button.



![](https://portal.parsec-corp.com/hc/article_attachments/18542839417363)

  * On the resulting page, an entry containing the License Serial Number will be displayed.



![](https://portal.parsec-corp.com/hc/article_attachments/41175366381715)

#### **The TrakSYS Web**

The License Serial Number can be found in the License page within the TrakSYS Web. In order to access this page, do the following:

  * Open the TrakSYS Web.
  * Navigate to **Administration | Diagnostics | License**.
  * The Serial Number should display in the first slice of the License page.



![](https://portal.parsec-corp.com/hc/article_attachments/41175353833235)
