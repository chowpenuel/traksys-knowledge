# DatabaseCommandTimeout

```csharp
int DatabaseCommandTimeout
```

Specifies the configured Command Timeout for the connection to the TrakSYS database. This option is configured within the Database tab of the TrakSYS Installation Manager.

{% hint style="info" %}
If the Command Timeout setting in the TrakSYS Installation Manager is changed, a Reload Application must be performed before the new value can be displayed when using this variable.
{% endhint %}
