# Aggregate Tag

## Summary

### Entity Name

Aggregate Tag

### Database Table Name

`tTag`, `tTagAggregate`

### API Object Name

`DbTagAggregateComposite`

### Entity Description

Aggregate Tags allow for common operations to be made on a list of Tags.

## Properties

`Operation [ Operation ] : ETS.Core.Enums.TagAggregateOperation`

Specifies the operation that is performed on the list of Tags defined in the Aggregate Tag. Options include **Sum**, **Average**, **Min** and **Max**.
