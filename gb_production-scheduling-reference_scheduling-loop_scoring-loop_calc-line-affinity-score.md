# Calculate Line Affinity Score

This method is used to change the score based on the Job being run on the selected System. This value returns a double value to set the Line Affinity Score for the Job and System combination.

## Context

`PsJobScoreInfo ScoreInfo`

Gets a PsJobScoreInfo object for the job and system combination. This object holds properties that give information on the Job, System, and Product that is currently being scored.
