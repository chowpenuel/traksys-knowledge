# State Machine State

## Summary

### Entity Name

State Machine State

### Database Table Name

`tStateMachineState`

### API Object Name

`StateMachine`

### Entity Description

Each row in this table represents a configured State for a State Machine.

## Properties

`State Machine ID [ StateMachineID ]`

Specifies the parent State Machine.

`Value [ Value ]`

The configured value for the corresponding State Key.
