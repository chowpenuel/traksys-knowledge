# Example Batch Plugin Execution

*Source: https://portal.parsec-corp.com/hc/en-us/articles/31138911010067-Example-Batch-Plugin-Execution*
*Last updated: 2024-07-09T13:04:38Z*

---

Applies To | TrakSYS 11 | TrakSYS 12

### Summary

Production Scheduling plugins come in two formats, one for discrete system use and one for batch system use. Each version comes with scripting hooks that can be used to add implementation-specific logic to the standard scheduling logic. However, without a previous understanding of the logic, it is not always clear when each method will execute.

  * Runs against a PsSet with 2 Systems (IDs: 1, 2)

There is an additional hook called PostScheduleInfoCompleteWithUnscheduledJobs. This hook runs once if any Jobs were marked as Unscheduled. It is not shown in the example, since the example assumes all jobs are able to be scheduled.

Attached is a plugin used track these outputs. It can be implemented for any Batch Production Scheduling Set and does not affect the base APS logic. It will output messages to tLogCustom to assist with tracking and understanding the order of execution for the various methods.

For more information on some of the common hooks and their uses, see [Production Scheduling: Plugin Hooks](https://portal.parsec-corp.com/hc/en-us/articles/360046038433).
