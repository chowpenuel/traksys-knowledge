# Connected Worker

## Overview

The **Connected Worker Functional Solution** connects teams with the tasks, workflows, notifications, and production context they need to manage daily operations more effectively. It includes a complete package of user interfaces for both end-users and admins for leveraging various TrakSYS functionality with simplified configuration requirements.

## Capabilities

Capabilities of the Connected Worker Solution derive from the Blocks it is build upon, most notably:

* Manage Order Execution from Start to Completion
* Manage Work Assignments and Follow-Up
* Guide Operators through Assigned Work
* Log Operational Events and Notes
* Capture Structured Operational Data
* Provide Access to Digital Procedures
* Review Shift and System Activity
* Manage Work Instructions and References
* Provide Current Production Context
* Standardize Operational Communication
* Capture Attachments and Supporting Evidence
* Support Supervisor Review and Corrections
* Standardize Connected Worker Workflows
* Access Historical Work Activity
* Drive Timely Operational Notifications

## Dependencies

This section lists dependencies for TrakSYS Features required by this Solution.

### License

The license requirements for the Connected Worker Functional Solution are a combination of the license requirements of the Blocks which its comprised. These Blocks primarily require TrakSYS Users, Advanced Scripting, Task Definitions, Workflow (if applicable), and Function Definitions (applicable for Batching only).

* **TrakSYS Users** - Allows end-users to access TrakSYS user interfaces concurrently.
* **Advanced Scripting** - Allows for extensibility via Visual Page Definitions, Content Parts and Pages, and Script Classes.
* **Task Definitions** - The base entity around which Tasks are instanced and implemented.
* **Workflow / Process Definitions** - Allow for automated workflows to trigger and process Tasks, handle Task escalations, and automating more complex business rules.
* **Batching / Function Definitions** - Required if TrakSYS, and this Functional Solution, is being deployed in a Batching environment. The Function Definitions are instanced as Batch Recipe Steps.
