# ENTITY Type

## Summary

### Entity Name

\[ENTITY] Type

### Database Table Name

`t[ENTITY]Type`

### API Object Name

`Db[ENTITY]Type`

### Entity Description

Entity Types are extensible configuration used to add further granularity to hierarchical structures for Configuration Entities. These Entities will typically store the values in a table with the Entity Name followed by Type (e.g., tSystemType, tTagType, tAreaType, etc.).

`PageKey01 - 03`

A extensibility field used to define a type-specific Page Key for navigation based on configured conditionals.

`ScriptClassName01 - 03`

A extensibility field used to define a type-specific Script Class Name that can be called in script based on configured conditionals.
