# KPI Capture Scheme (OEE Capture Scheme)

## Summary

### Entity Name

KPI Capture Scheme

### Database Table Name

`tOeeCaptureScheme`

### API Object Name

`DbOeeCaptureScheme`

### Entity Description

A KPI Capture Scheme defines the Capture Columns associated with a KPI Calculation. Once you assign a Capture Tag to a Capture Scheme Column in your KPI Calculation, the Logic Service will record the values of the Capture Tag as supplementary data in a matching column for each Interval. Capture Tags work similarly to VTRs, but the reports allow you to report by Capture Columns rather than merely view the Captured values in a detail view. Common Capture Columns are Job, Batch, and Lot Number.
