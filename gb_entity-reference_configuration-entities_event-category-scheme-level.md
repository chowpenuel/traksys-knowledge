# Event Category Scheme Level

## Summary

### Entity Name

Event Category Scheme Level

### Database Table Name

`tEventCategorySchemeLevel`

### API Object Name

`DbEventCategorySchemeLevel`

### Entity Description

An Event Category Scheme Level is a label for a level of hierarchy in the Event Category Tree View structure. These labels are used for reference in TrakSYS menus and reports.

## Properties

`Event Category Scheme [ EventCategorySchemeID ]`

Specifies the parent Event Category Scheme.

`Level`

Indicates the level in the Event Category hierarchy (an `integer` 1 - 10)
