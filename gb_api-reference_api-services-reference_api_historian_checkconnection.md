# CheckConnection

```csharp
Result<bool> CheckConnection()
```

Returns true if the connection to the Historian Database is successful, otherwise returns false.

## Examples

### Check the connection to the Historian Database

This example was created within a Button Click method for a Buttons Part on a Visual Page Definition. However, similar code can be used in other areas of the application (with slight syntax changes). The different ways to access the TrakSYS API within each area of the application can be found [**here**](https://portal.parsec-corp.com/hc/en-us/articles/43625704630035-Instantiating-the-API-Service).

```csharp
private void ButtonClick(object sender, EventArgs e)
{
  try
  {
    // Check the connection to the Historian Database
    bool historianConn = this.Ets.Api.Historian.CheckConnection().ThrowIfFailed();

    // The variable can be used in code as needed...
  }
  catch (Exception ex)
  {
    // Throw error messages if the process fails.
    this.Ets.Debug.FailFromException(ex);
  }
}
```
