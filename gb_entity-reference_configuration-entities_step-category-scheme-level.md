# Step Category Scheme Level

## Summary

### Entity Name

Step Category Scheme Level

### Database Table Name

`tStepCategorySchemeLevel`

### API Object Name

`DbStepCategorySchemeLevel`

### Entity Description

A Step Category Scheme Level is a label for a level of hierarchy in the Step Category Tree View structure. These labels are used for reference in TrakSYS menus and reports.

## Properties

`Step Category Scheme [ StepCategorySchemeID ]`

Specifies the parent entity in the configuration hierarchy.

`Level`

Indicates the level in the Event Category hierarchy (an `integer` 1 - 10).
