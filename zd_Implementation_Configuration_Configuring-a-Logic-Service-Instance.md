# Configuring a Logic Service Instance

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360017372174-Configuring-a-Logic-Service-Instance*
*Last updated: 2026-03-03T01:10:56Z*

---

Applies To | TrakSYS 10+

In order to start Logic Service, a configuration entry must exist for it.

The following describes how to create and configure a Logic Service entry in the configuration:

  1. Open the TrakSYS Web and click the Configuration section.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18704643897747)  
  

  2. Next, navigate to **Services | Logic Services**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18704701777043)  
  

  3. Click the New button in the first slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18704664850707)  
  

  4. In the General tab of the Logic Service properties window, enter a Name for the Logic Service and enter the Computer Name of the server where TrakSYS is installed. Please note if there are any mistakes in the name, the Logic Service will not start.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18704743402259)  
  

  5. Click the Save button to save the changes.
  6. The newly created Logic Service entry should now appear in the Logic Services slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18704731019411)  
  

  7. Open Installation Manager, select the Logic Service and Start the service.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18704769371027)  
  

  8. Now that a Logic Service entry has been created and is properly configured, the Logic Service should successfully start.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18704781690131)
