# Lookup Set

## Summary

### Entity Name

Lookup Set

### Database Table Name

`tLookupSet`

### API Object Name

`DbLookupSet`

### Entity Description

A Lookup Set contains one or more key/value pairs called Lookup Values. Lookup Sets provide configurable structured lists that can be used and referenced by scripts, dashboards and other user interfaces throughout the installation.

## Properties

`Data Type [ DataType ]`

The intended data type of the "Value" property for all Lookup Values configured for this Lookup Set.
