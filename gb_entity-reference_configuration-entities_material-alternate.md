# Material Alternate

## Summary

### Entity Name

Material Alternate

### Database Table Name

`tMaterialAlternate`

### API Object Name

`DbMaterialAlternate`

### Entity Description

A Material Component is a reference and quantity of another existing Material. They are used to construct compound Materials.

## Properties

`MaterialID [ MaterialID ]`

Specifies the parent Material.

`Material Alternate [ AlternateMaterialID ]`

The referenced Material that can be used as an alternate to the parent Material.
