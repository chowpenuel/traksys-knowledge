# Task VTR

## Summary

### Entity Name

Task Vtr

### Database Table Name

`tTaskVtr`

### API Object Name

`DbTask`

### Entity Description

Each row in this table represents a Tag Value that is recorded when the associated Task is created.

## Properties

`TaskID`

Identifies the Task which has been created and triggers the recording of a Tag Value.

`TaskVtrDefinitonID`

Identifies the Task VTR Definition which this Task VTR is based.

`TagValue`

The recorded Tag Value (of the Tag configured in the Task VTR Definition) at the time of the Task creation.
