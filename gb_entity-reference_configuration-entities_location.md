# Location

## Summary

### Entity Name

Location

### Database Table Name

`tLocation`

### API Object Name

`DbLocation`

### Entity Description

A Location represents a physical location in the manufacturing process. Locations are used to spatially categorize Items and indicate the position of assets in TrakSYS.

## Properties

`Location Type [ LocationTypeID ]`

A Location Type categorizing this Location (solely for organizational and reporting purposes).

`Parent Location [ ParentLocationID ]`

Specifies the parent Location.

`Unique Identifier [ UniqueID ]`

The unique string identifying the Location.
