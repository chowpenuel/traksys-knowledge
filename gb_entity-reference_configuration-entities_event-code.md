# Event Code

## Summary

### Entity Name

Event Code

### Database Table Name

`tEventCode`

### API Object Name

`DbEventCode`

### Entity Description

Event Codes help organize similar or related Event Categories. These may be useful for relating Event Categories to an existing business categorization scheme. Once Event Categories have been related to Event Codes, the corresponding Event Code will be assigned when operators categorize an Event.

## Properties

`Event Code Group [ EventCodeGroupID ]`

Specifics the parent Event Code Group.

`Code`

Custom alphanumeric `string` which uniquely identifies the Event Code.
