# Generating Custom Property Views in the TrakSYS Database

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115004919974-Generating-Custom-Property-Views-in-the-TrakSYS-Database*
*Last updated: 2025-05-21T22:15:54Z*

---

Applies To | TrakSYS 10+

The Custom Property Views need to be generated using the TrakSYS Web. They can be generated as follows:

  1. Open the TrakSYS Web and navigate to **Configuration | Custom Properties**.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18843992604819)  
  

  2. Under the Schemes section in the first slice, click the Generate Views button.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18844025595667)  
  

  3. Click the Generate button in the second slice.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18844041160339)  
  

  4. The Views should now appear in the TrakSYS Database.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18844058252179)
