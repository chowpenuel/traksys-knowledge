# DateTimeRange

This object model is used to provide a default Start and End Date/Time range. While the primary use for this object is in Algorithmic Production Scheduling (APS), it can also be used for other entities to provide a default Date/Time range.

## Properties

`DateTimeOffset EndDateTimeOffset`

Gets or sets the default End Date/Time Offset value for this object.

`DateTimeOffset StartDateTimeOffset`

Gets or sets the default Start Date/Time Offset value for this object.
