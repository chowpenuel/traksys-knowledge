# Icon\_ActiveComplete

#### Icon | Active

Specifies icon CSS to be returned in the column called **IconCssActive** when the item represented by the row is currently **active** (in-progress/due). This column in the resultant dataset can be used to dynamically populate icon properties in table and list parts.

#### Icon | Complete

Specifies icon CSS to be returned in the column called **IconCssActive** when the item represented by the row is currently **complete** (ended/completed). This column in the resultant dataset can be used to dynamically populate icon properties in table and list parts.
