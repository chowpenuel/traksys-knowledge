# Fast Update Set

### Entity Name

Fast Update Set

### Database Table Name

`tFastUpdateSet`

### API Object Name

`DbFastUpdateSet`

### Entity Description

Fast Update Sets list the available Fast Update Tags configured under them. Multiple Sets may be created for organizational purposes or to separate Fast Update Tags by Web Host.

## Properties

`WebHost`

Specifies the Web Host URL to broadcast the Fast Update Tag value updates.
