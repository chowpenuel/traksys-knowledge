# Verifying the Installed Version

*Source: https://portal.parsec-corp.com/hc/en-us/articles/236323008-Verifying-the-Installed-Version*
*Last updated: 2026-03-05T23:14:45Z*

---

Applies To | TrakSYS 10 | TrakSYS 11 | TrakSYS 12

### **Summary**

The following article describes the two options available for determining the installed version of TrakSYS.

#### **Option 1: TrakSYS Installation Manager**

  * From the Overview tab of Installation Manager, select Version Information from the right-side menu.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/19162108914707)  
  

  * The TrakSYS Version Summary will be displayed, including the current version number.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/19162158373267)



#### **Option 2: TrakSYS Web**

  * Navigate to the Administration section of the TrakSYS Web and select Settings from the left-hand menu.
  * Alternatively, enter the URL directly in the navigation bar (note: a site key can be used instead of "home" for multi-site installations): http://server/TS/pages/home/admin/settings/  
  
![](https://portal.parsec-corp.com/hc/article_attachments/19162155767827)
