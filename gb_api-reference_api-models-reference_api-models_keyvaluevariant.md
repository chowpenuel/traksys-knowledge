# KeyValueVariant

This Object Model is used when interacting with Variant values. The DataType field contains the actual data type while the other fields are simply a key/value pair.

## Properties

`DataType DataType`

This field contains the actual data type of the Variant value. The enumeration values for this field can be found under `ETS.Core.Enums.DataType`.

`string Key`

Specifies the `Key` used when a Variant value is processed.

`string Value`

Specifies the raw value when a Variant value is used.
