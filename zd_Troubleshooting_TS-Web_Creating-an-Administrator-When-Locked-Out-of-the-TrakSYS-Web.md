# Creating an Administrator When Locked Out of the TrakSYS Web

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360003816713-Creating-an-Administrator-When-Locked-Out-of-the-TrakSYS-Web*
*Last updated: 2025-05-21T23:11:56Z*

---

Applies To | TrakSYS 10+

### **Summary**

While developing within TrakSYS and configuring permissions it is possible to be locked out of the TrakSYS Web if no configured users are administrators or have permissions to access any of the pages. In this scenario, the option to create administrative TrakSYS users is available in the TrakSYS Installation Manager. This article will explain how to create an administrative user and regain access to the TrakSYS Web.

### **Procedure**

  1. Open the TrakSYS Installation Manager.
  2. Navigate to the Sites section.
  3. Click the Repair Administrator button.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18702111471379)  
  

  4. In the Create Administrator dialog, type the name of the administrative user in the Name field. Then, type a Login and Password for the account. These are the credentials that will be used to log into the TrakSYS Web.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18702141531283)  
  

  5. Open the TrakSYS Web and enter the credentials of the newly created administrative account to login.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18702244319379)  
  

  6. The account should now have full access to the TrakSYS Web. If the account needs to be modified or deleted, navigate to **Administration | Users**.   
  
![](https://portal.parsec-corp.com/hc/article_attachments/18702248116243)  
  

  7. The account should be present under the Users section on the second slice of the page.  
  
![](https://portal.parsec-corp.com/hc/article_attachments/18702416265619)
