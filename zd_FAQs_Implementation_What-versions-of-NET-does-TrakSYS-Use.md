# What versions of .NET does TrakSYS Use?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/34772588623123-What-versions-of-NET-does-TrakSYS-Use*
*Last updated: 2026-03-31T03:13:43Z*

---

The .NET versions used by the latest TrakSYS releases are listed below.

**Note:** Starting with version 5, Microsoft has dropped the term "Core" from its naming conventions.

### TrakSYS 11

#### All Versions

**TrakSYS Web** : .NET Framework 4.8

**TrakSYS Application** : .NET Framework 4.8

### TrakSYS 12

#### 12.0.0 through 12.0.2

**TrakSYS Web** : .NET Framework 4.8

**TrakSYS Application** : .NET 6.0

#### 12.0.3 and 12.0.4

**TrakSYS Web** : .NET Framework 4.8

**TrakSYS Application** : .NET 8.0

### TrakSYS 13

#### All Versions

**TrakSYS Web** : .NET Framework 4.8

**TrakSYS Application** : .NET 8.0

### TrakSYS 14

#### 14.0.0

**TrakSYS Web** : .NET Framework 4.8

**TrakSYS Application** : .NET 8.0
