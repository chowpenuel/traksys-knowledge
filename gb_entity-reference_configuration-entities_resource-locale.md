# Resource Locale

## Summary

### Entity Name

Resource Locale

### Database Table Name

`tResourceLocale`

### API Object Name

`DbResourceLocale`

### Entity Description

Resource Locales define the supported locales (cultures) used by TrakSYS Translations. Locale selection typically comes from the user’s locale (`tUser.Locale`) or the browser/environment locale. Locales use Microsoft culture names.

## Properties

`Culture Name [ CultureName ]`

Locale culture name (Microsoft culture format), such as `en`, `en-US` or `es-MX`.
