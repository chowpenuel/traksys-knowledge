# Log

## Summary

### Entity Name

Log

### Database Table Name

`tLog`

### API Object Name

`DbLog`

### Entity Description

Each row in this table contains log entries for the TrakSYS application. This is where the information for the primary TrakSYS log file is stored (errors, warnings, informational messages, etc.). Entries for this table are automatically generated by the TrakSYS and can also be generated programmatically using the TrakSYS API.

## Properties

`LogDateTime`

The date and time that the log entry was created by the TrakSYS software or API script call.

`Host`

Specifies the computer name of the machine where the message originated.

`Application`

Specifies the part of the application where the message originated. Typical values for this field include any of the TrakSYS services and the TrakSYS Web.

`ApplicationVersion`

The version of TrakSYS that was used when the message was generated.

`Message`

Contains the text message when the error, warning, or informational message was created.

`Category`

Specifies the category that the message belongs to when it was generated. TrakSYS has a number of built-in categories, however, custom categories can also be defined if the message is generated programmatically using the TrakSYS API.

`Type : ETS.Core.Enums.LogType`

This is an enumeration representing the type of Log message.

* **Information** = 1
* **Warning** = 2
* **Error** = 3

`Location`

Specifies the location of the message. Depending on the location, this value can be obfuscated.

`StackTrace`

Contains the programmatic stack trace for the message. This value will always be partially or completely obfuscated.

`Data`

Contains any additional data that was included with the Log message.

`ManagerID`

Specifies the service instance ID of the TrakSYS service that created the log entry. For example, if the Logic Service created the entry, it will contain the `tLogicManager.ID` value of the configured Logic Service Instance.
