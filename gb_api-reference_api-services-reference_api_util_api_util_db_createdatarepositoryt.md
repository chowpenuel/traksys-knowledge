# CreateDataRepository\<T>

```csharp
IDataRepository<T> CreateDataRepository<T>()
```

Creates an instance of an [IDataRepository\<T>](../../idatarepositoryt) class. The structure of the API and the methods are distributed across many different classes. With the `IDataRepository` class, all basic CRUD (Create, Read, Update and Delete) operations are located in one single class.
