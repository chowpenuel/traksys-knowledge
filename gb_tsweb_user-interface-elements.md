# User Interface Elements

The TrakSYS Web environment is comprised of a variety of user interface elements. These standardized elements create a simple navigation experience throughout the application.

## Header

The Header appears at the very top of the TrakSYS Web application. It displays the Site, Sections, Log In/Out, and optionally the current time. Using Page properties, the Header can be hidden when desired.

## Company Logo

The Company Logo is displayed at the leftmost edge of the Header. By default this is a TrakSYS logo, however this can be customized in TrakSYS Settings.

## Application Title

The Application Title is displayed beside the Company Logo and is comprised of the Company Name (from the currently activated License) and the Site name.

## User Menu

The User Menu is made visible when clicking the currently logged on User at the rightmost edge of the Header. The menu displays links to Log Off, Settings, and Sites (in Multi-Site installations).

## Footer

The Footer appears at the very bottom of the TrakSYS Web application. When an authorized user is browsing page definitions, options to edit the page, properties, etc. become available in the center of the Footer.

## Tree

The Tree is visible along the entire left edge of the TrakSYS Web application. The Tree displays both level 1 Hubs and level 2 Hubs. Using Page properties, the Tree can be hidden when desired.

## Breadcrumbs

Breadcrumbs appear just below the Header at the top of a Page and display a link trail of the Page's parent hierarchy. Using Page properties, Breadcrumbs can be hidden when desired.

## Page Title

The Page Title is displayed at the top of each page, just under the Breadcrumbs. Using Page properties, the Page Title can be hidden when desired.

## Slices

Slices are used throughout the TrakSYS Web application to display entities that are grouped, such as Tags and Products. For example, when viewing many Configuration pages, the Page may be "sliced" into three columns. The left Slice typically displays the Entity Groups, the middle Slice typically displays the Entities within the selected group, and the third column typically shows Details and Operations pertaining to the selected Entity.

## Slice Menu

Just above a Slice may be a menu. Typically when a Slice is used to display a list of groups or entities, the Slice Menu may include options to add new or reorder.

## Related

The Related menu is typically displayed to the right of Slices, and shows links to Pages related to the selected entity.

## Operations (Common and Actions)

Operations are typically displayed to the right of Slices, and show relevant links to actions pertaining to the selected entity. For example, selecting a System entity in the Configuration section reveals Actions for setting the System Capture Scheme or Creating a Template Parent System from the selected System entity.

## Spoke Links

Spokes links are displayed on the top right of the Page just under the Header, they display links to the Spokes available at this level of the Page hierarchy. Using Page properties, Spoke links can be hidden when desired.
