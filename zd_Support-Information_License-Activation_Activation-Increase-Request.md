# Activation Increase Request

*Source: https://portal.parsec-corp.com/hc/en-us/articles/115000983994-Activation-Increase-Request*
*Last updated: 2026-01-16T19:18:25Z*

---

To request additional activations of a TrakSYS license file, please [submit a License Activation Increase Request](https://portal.parsec-corp.com/hc/en-us/requests/new?ticket_form_id=13514752992275). The [license serial number](https://portal.parsec-corp.com/hc/en-us/articles/360003777014), a 10-digit number prefixed with the letters "SN" (e.g. SNXXXXXXXXXX), will be required. A license's remaining activations can be checked as described [here](https://portal.parsec-corp.com/hc/en-us/articles/115000983974).  
  
The activation increase request will be processed by a Support Engineer for approval. **You should receive an email confirmation response to the address provided within an hour, indicating that the activation limit has been increased.**
