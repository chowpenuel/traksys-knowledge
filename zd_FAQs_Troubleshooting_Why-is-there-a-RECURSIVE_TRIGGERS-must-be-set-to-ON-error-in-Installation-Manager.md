# Why is there a "RECURSIVE_TRIGGERS must be set to ON" error in Installation Manager?

*Source: https://portal.parsec-corp.com/hc/en-us/articles/360004061853-Why-is-there-a-RECURSIVE-TRIGGERS-must-be-set-to-ON-error-in-Installation-Manager*
*Last updated: 2025-05-28T17:57:56Z*

---

Applies To | TrakSYS 10+

The "RECURSIVE_TRIGGERS must be set to ON" error can appear in the Database tab of Installation Manager when the Recursive Triggers option for the TrakSYS Database is disabled.

The Recursive Triggers option allows triggers to be called by other triggers.
