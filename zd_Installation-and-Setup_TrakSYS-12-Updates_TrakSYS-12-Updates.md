**Download Information**  
  
This download contains a single update executable. The executable updates all necessary files for TrakSYS 12. All TrakSYS 12 updates are cumulative. To update TrakSYS 12 to the latest version, only the last update needs be downloaded and installed.  
  
**Installation Instructions**

  * The [full setup](https://portal.parsec-corp.com/hc/en-us/articles/16766319844243) for TrakSYS version 12 must be installed on the target machine prior to running the update executable. **Do not apply the update if version 12 is not installed on the target machine**.
  * Stop all TrakSYS services/applications before the patch executable is run. This includes the TrakSYS Logic, Historian, Data Management, Workflow, and Maintenance services.
  * Backup the TrakSYS database before the update executable is run.
  * After the update executable is run, restart applicable TrakSYS services and applications.
