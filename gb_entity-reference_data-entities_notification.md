# Notification

## Summary

### Entity Name

Notification

### Database Table Name

`tNotification`

### API Object Name

`DbNotification`

### Entity Description

Each value in this table represents an actual message that was (or is to be) sent as the result of Notification Definition and Notification Target configuration. As messages are generated by TrakSYS behavior, or API script calls, the message content and expected target email addresses are added to this table. The Maintenance Service processes unsent messages from this table, sends them out, and then updates the State fields to indicate success or failure.

## Properties

`NotificationDefinitionID`

The unique identifier (primary key) of the Notification Definition which defines the content to be sent.

`NotificationTargetID`

The unique identifier (primary key) of the Notification Target which defines the target Users the message will be sent to.

`NotificationDateTime`

The date and time that the Notification message is created by the Logic Service or API script call.

`ShiftHistoryID`

The unique identifier (primary key) for the Shift (Shift History record) that was in progress when the Notification was created.

`Title`

The content that will be used for the message title (title of an email).

`Body`

The content that will be used for the message body (body of an email).

`BodyRetrieveAndEmbed`

A configuration setting (copied from the parent Notification Definition) that determines if the message Body is to be interpreted as a link to a page that will be retrieved and embedded in the message (making up the actual body of the email).

`Args`

The values to be passed from the execution (Logic Service or API call) to the Notification Definition message. These values are available to TrakSYS expressions within the Title and Body content to inject dynamic data into the message.

`State : ETS.Core.Enums.NotificationStateType`

This is an enumeration representing the state of the message.

* **Pending** = 1
* **CompleteOK** = 2
* **CompleteError** = 3

`StateDateTime`

Specifies the last Date/Time that the State field was changed.

`StateMessage`

Any additional information regarding the current message state. This is typically error message content when the State is 3.
